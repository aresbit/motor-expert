# 第7章: 感应电机的解析设计评估 (Analytic Design Evaluation of Induction Machines)
> 原课程: MIT 6.685 — Electric Machines, Fall 2013 (James L. Kirtley Jr.)

## 一、本章概要 (Overview)

感应电机（induction machine）是使用最广泛的电机类型。它结构简单、坚固耐用，具备合理的异步运行性能：可控的转矩-转速曲线、带载下的稳定运行以及一般满意的效率。此外，一些新应用（例如燃气压缩机用高速电机，可能采用鼠笼转子或实心铁转子）要求的特性与现有商品电机不同，因此需要从第一性原理理解感应电机。这正是本章笔记（Class Notes 8）的目标。

本章的核心问题是如何对感应电机做解析设计评估（analytic design evaluation）：从尺寸与材料性质出发，计算气隙磁导、激磁电抗、漏抗、转子电阻等等效电路参数，再由等效电路计算转矩、功率、效率与功率因数。分析的起点是变压器模型的电路观点，该模型严格适用于绕线转子电机，但可推广到更复杂的鼠笼电机。随后用场分析技术推导鼠笼电机的电路模型，讨论深槽与双鼠笼转子对起动性能的作用。全章方法属于经典解析方法，不借助数值分析或经验拟合。

与前后章节的关系：第 4 章建立了绕组电感的一般表达式，本章把该框架具体化为感应电机的气隙磁导与漏感模型；第 6 章讨论永磁无刷直流电机，其转矩由永磁磁场与电枢电流相互作用产生，而本章的感应电机转矩依靠转子中感应电流产生。本章末尾给出不同频率下的转矩-转速曲线与恒压频比（volts/Hz）概念，为后续变频调速与磁场定向控制奠定基础。

## 二、物理机制与数学推导 (Physics & Math Derivation)

### 2.1 结构

感应电机有两个同轴的电学有源元件：定子（stator）与转子（rotor）（笔记 Figure 1）。定子铁心内表面开槽，槽内放置多相绕组；正常运行时定子由对称交流电压激励。转子同样开槽，槽内放置绕组或鼠笼。鼠笼转子（squirrel-cage rotor）的导体为若干条轴向导条（bar），两端由端环（end ring）短接；绕线转子（wound rotor）带有与定子类似的三相绕组，经滑环（slip ring）引出，可在转子回路中串入外部电阻。

### 2.2 工作原理

定子对称电流建立磁动势，其空间分布是一个旋转行波（rotating wave）。该行波以电气角频率 $$\omega$$ 旋转，切割转子导体，由法拉第定律在转子回路中感应电压与电流。转子电流与行波磁场相互作用，由洛伦兹力产生转矩。若转子转速恰好等于行波同步转速，转子导体不再切割磁场，感应电流消失，转矩为零。因此电动机运行必须低于同步转速，感应电机因此也称为异步电机（asynchronous machine）。

这一机制与传统变压器有本质差别。变压器中磁场静止，副边电流与磁场之间没有相对运动，只传递功率而不产生机械输出；感应电机的行波磁场与转子电流之间存在由转差率决定的相对运动，这正是转矩的来源。转子电流由磁场感应产生，属于异步建立，不需要转子侧励磁。转子电流在定子中产生的磁场与定子磁动势相互作用，合成气隙场；由转差率决定的气隙功率在转子电阻损耗 $$sP_{ag}$$ 与机械输出 $$(1-s)P_{ag}$$ 之间的分配，是感应电机能量平衡的核心。

### 2.3 转差率与转子频率

设极对数为 $$p$$，定子电气频率为 $$\omega$$，转子机械转速为 $$\omega_m$$，则行波相对转子的电气角速度为 $$\omega - p\omega_m$$，这正是转子电流的电气频率：

$$\omega_R = \omega - p\omega_m$$

定义转差率（slip）：

$$s = \frac{\omega_R}{\omega} = 1 - \frac{p\omega_m}{\omega}$$

转子静止时 $$\omega_m = 0$$，$$s = 1$$，转子频率等于定子频率；转子达到同步转速时 $$s = 0$$，转子频率为零。电动机运行区间为 $$0 < s < 1$$；发电机运行（转子高于同步转速）对应 $$s < 0$$；反接制动对应 $$s > 1$$。转差率同时决定了转子回路的感应频率与转子电阻损耗，是感应电机分析的核心变量。

### 2.4 磁链-电流关系与变压器模型

设定子三相电流对称（笔记式 5）：

$$i_a = I_S\cos\omega t, \qquad i_b = I_S\cos\left(\omega t - \frac{2\pi}{3}\right), \qquad i_c = I_S\cos\left(\omega t + \frac{2\pi}{3}\right)$$

转子电流对称，频率为 $$\omega_R$$（笔记式 6）。转子位置 $$\theta = \omega_m t + \theta_0$$。定子与转子三相绕组之间由随位置变化的互感耦合。计算定子 a 相磁链并化简三角项（笔记式 9）：

$$\lambda_a = (L_a - L_{ab}) I_S \cos\omega t + \frac{3}{2} M I_R \cos\left((p\omega_m + \omega_R)t + \xi_R + p\theta_0\right)$$

匹配条件 $$p\omega_m + \omega_R = \omega$$ 使转子电流在定子中产生的磁链以定子频率振荡，因此转子量可以折算到定子参考系。转子 a 相磁链（笔记式 11）：

$$\lambda_A = \frac{3}{2}M I_S\cos\left((\omega - p\omega_m)t - p\theta_0\right) + (L_A - L_{AB})I_R\cos(\omega_R t + \xi_R)$$

引入复数相量并定义折算到定子相角的转子磁链与电流相量，得到等效的单相磁链-电流关系（笔记式 21）：

$$\tilde{\Lambda}_a = L_S \tilde{I}_a + \frac{3}{2}M\tilde{I}_{AR}, \qquad \tilde{\Lambda}_{AR} = \frac{3}{2}M\tilde{I}_a + L_R \tilde{I}_{AR}$$

其中 $$L_S = L_a - L_{ab}$$、$$L_R = L_A - L_{AB}$$ 为定子与转子的同步电感。端电压方程为（笔记式 24-25）：

$$\tilde{V}_a = j\omega L_S \tilde{I}_a + \frac{3}{2}j\omega M \tilde{I}_{AR} + R_a \tilde{I}_a$$

$$\tilde{V}_{AR} = j s\omega \frac{3}{2}M \tilde{I}_a + j s\omega L_R \tilde{I}_{AR} + R_A \tilde{I}_{AR}$$

### 2.5 气隙磁导与同步电感

同步电感可分离为空间基波分量与漏分量。定义气隙磁导（air-gap permeance）（笔记式 29）：

$$\wp_{ag} = \frac{4\mu_0 R l}{\pi p^2 g}$$

其中 $$R$$ 为转子半径，$$l$$ 为有效长度，$$g$$ 为有效气隙。于是（笔记式 30-32）：

$$L_S = \frac{3}{2}\wp_{ag} k_S^2 N_S^2 + L_{Sl}, \qquad L_R = \frac{3}{2}\wp_{ag} k_R^2 N_R^2 + L_{Rl}, \qquad M = \wp_{ag} N_S N_R k_S k_R$$

$$N$$ 为匝数，$$k$$ 为绕组因数，下标 $$S$$、$$R$$ 分别指定子与转子，$$L_{Sl}$$、$$L_{Rl}$$ 为漏电感。漏感包含高次空间谐波电感、槽漏感、端部漏感以及斜槽效应，代表转子与定子中所有未被互相耦合的磁通。

### 2.6 等效电路

把转子电流折算到定子，使折算后的电流产生与转子电流相同的基波磁动势：

$$\tilde{I}_2 = \frac{N_R k_R}{N_S k_S}\tilde{I}_{AR}$$

设转子短路（$$\tilde{V}_{AR} = 0$$，鼠笼与短路运行的绕线转子均如此），化简后得到（笔记式 38-39）：

$$\tilde{V}_a = j(X_M + X_1)\tilde{I}_a + jX_M\tilde{I}_2 + R_a\tilde{I}_a$$

$$0 = jX_M\tilde{I}_a + j(X_M + X_2)\tilde{I}_2 + \frac{R_2}{s}\tilde{I}_2$$

其中参数定义为：

$$X_M = \frac{3}{2}\omega\wp_{ag}N_S^2k_S^2, \qquad X_1 = \omega L_{Sl}, \qquad X_2 = \omega L_{Rl}\left(\frac{N_S k_S}{N_R k_R}\right)^2, \qquad R_2 = R_A\left(\frac{N_S k_S}{N_R k_R}\right)^2$$

$$X_M$$ 为激磁电抗（magnetization reactance），$$X_1$$ 为定子漏抗（stator leakage reactance），$$X_2$$、$$R_2$$ 为折算到定子的转子漏抗与电阻。该方程组描述笔记 Figure 2 的每相等效电路：

```text
        Ra        X1          X2        R2/s
  a ────┬─────────┬───────────┬─────────┬─────────┐
        │         │           │         │         │
        │         │           │         │         │
        │         │   jXm     │         │         │
        │         │           │         │         │
        │         │           │         │         │
  ──────┴─────────┴───────────┴─────────┴─────────┴───
```

定子电阻 $$R_a$$ 与漏抗 $$X_1$$ 串联后到达节点；节点处两条并联支路：激磁支路 $$jX_M$$ 直接回到底线，转子支路 $$jX_2$$ 串联 $$R_2/s$$ 回到底线。转子支路中电阻以 $$R_2/s$$ 出现，来自转子电压方程对转差率归一化的运算，其物理含义是折算后的转子回路在给定转差率下呈现的等效电阻。

### 2.7 转矩-转差特性与临界转矩

转子支路中 $$R_2/s$$ 上的功率为跨过气隙传递到转子的功率，即气隙功率（air-gap power），三相总值为：

$$P_{ag} = 3\lvert\tilde{I}_2\rvert^2\frac{R_2}{s}$$

其中一部分在物理转子电阻中耗散：

$$P_s = sP_{ag}$$

其余转换为机械功率：

$$P_m = P_{ag} - P_s = (1-s)P_{ag}$$

转矩等于机械功率除以机械转速，或用气隙功率除以同步机械角速度（笔记 MATLAB 脚本中 $$T = P_{ag}/\Omega_s$$）：

$$T_e = \frac{P_m}{\omega_m} = \frac{P_{ag}}{\omega_s} = \frac{3p}{\omega}\lvert\tilde{I}_2\rvert^2\frac{R_2}{s}$$

对忽略定子电阻与激磁支路的简化电路，把电压 $$\tilde{V}$$ 直接加在 $$j(X_1+X_2) + R_2/s$$ 上：

$$T_e = \frac{3p}{\omega}V^2\frac{R_2/s}{(X_1+X_2)^2 + (R_2/s)^2}$$

令 $$x = R_2/s$$，对函数 $$x/(a^2+x^2)$$（其中 $$a = X_1+X_2$$）求极值，由 $$\frac{d}{dx}\frac{x}{a^2+x^2} = \frac{a^2-x^2}{(a^2+x^2)^2} = 0$$ 得到功率传输匹配条件 $$x = a$$，即：

$$s_{max} = \frac{R_2}{X_1+X_2}, \qquad T_{max} = \frac{3pV^2}{2\omega(X_1+X_2)}$$

$$s_{max}$$ 为临界转差率，$$T_{max}$$ 为临界转矩（breakdown torque）。结论：简化电路下临界转矩与转子电阻无关，临界转差率与转子电阻成正比。这解释了两类设计措施。绕线转子电机起动时串入外部电阻，增大 $$R_2$$，使临界转差率接近 1，从而获得大起动转矩，起动后再切除电阻以恢复低损耗运行。深槽与双鼠笼转子利用集肤效应使转子电阻随频率自动变化，同样在不牺牲运行效率的前提下提高起动转矩。

## 三、模型与方法精解 (Models & Methods)

### 3.1 由等效电路计算性能

给定等效电路参数与端电压，性能计算顺序如下。气隙阻抗为激磁支路与转子支路并联（笔记式 44）：

$$\tilde{Z}_g = jX_M \parallel \left(jX_2 + \frac{R_2}{s}\right)$$

端阻抗与端电流（笔记式 45-46）：

$$\tilde{Z}_t = jX_1 + R_a + \tilde{Z}_g, \qquad \tilde{I}_t = \frac{\tilde{V}_t}{\tilde{Z}_t}$$

转子电流由电流分配关系得到（笔记式 47）：

$$\tilde{I}_2 = \tilde{I}_t\frac{jX_M}{jX_2 + R_2/s + jX_M}$$

电气输入功率为气隙功率加定子铜耗：

$$P_{in} = P_{ag} + 3\lvert\tilde{I}_t\rvert^2 R_a$$

轴输出功率为机械功率减去摩擦、风阻与杂散损耗 $$P_w$$：

$$P_{out} = P_m - P_w = (1-s)P_{ag} - P_w$$

效率与功率因数：

$$\eta = \frac{P_{out}}{P_{in}}, \qquad \cos\psi = \frac{P_{in}}{3V_t I_t}$$

转矩-转速曲线可对转差率扫描得到。曲线形状取决于参数，特别是 $$R_2/(X_1+X_2)$$ 决定临界转差率的位置。

### 3.2 解析设计评估流程

设计评估（design evaluation）的目标是从尺寸与材料性质直接计算机器的等效电路参数与性能。笔记给出的系统流程如下。

1. 由几何尺寸计算气隙磁导 $$\wp_{ag}$$，用卡特系数（Carter's coefficient）修正槽口对气隙磁导的削弱，得到激磁电抗 $$X_M$$。
2. 由端电压与绕组参数计算气隙磁通密度，用于铁心损耗估计与饱和检查。
3. 计算各漏抗分量：槽漏、带谐波漏、之字形漏、端部漏与斜槽效应。
4. 由导条截面与材料计算转子槽电阻与槽电感，折算为 $$R_2$$ 与 $$X_2$$，并加入端环电阻修正。
5. 由导线尺寸与端部长度计算定子电阻 $$R_1$$。
6. 组装等效电路，在额定转差率处计算性能；若结果偏离设计目标，调整槽形、导体尺寸与绕组参数后重复。

### 3.3 卡特系数

感应电机气隙很小，槽口会削弱气隙磁导，等效地增大气隙。有效气隙与物理气隙之比为（笔记式 68-69）：

$$\frac{g_{eff}}{g} = \frac{t+s}{t+s-gf(\alpha)}, \qquad f(\alpha) = \alpha\tan\alpha - \log(\sec\alpha)$$

其中 $$t$$ 为齿距，$$s$$ 为槽口宽度，$$\alpha \approx s/(2g)$$。

### 3.4 鼠笼转子参数

鼠笼没有离散绕组，分析以单根导条为对象。对称运行下第 $$k$$ 槽电流相位沿转子均匀递进（笔记式 71）：

$$\tilde{I}_k = \tilde{I}e^{-j2\pi pk/N_R}$$

转子表面电流密度展开为空间谐波。除基波（$$n=1$$）外，两个显著的谐波阶次为 $$n_+ = N_R/p + 1$$ 与 $$n_- = -(N_R/p - 1)$$，对应鼠笼节距谐波，产生额外的无功阻抗，即之字形漏感（zigzag leakage）。

谐波阶次的来源可由式 78 的求和看出：当 $$(n-1)p/N_R$$ 为整数时，各槽电流谐波同相叠加，求和才非零。基波 $$n=1$$ 对应主磁动势项，而 $$n = \pm N_R/p \mp 1$$ 对应的磁场波在气隙中形成短节距波，其磁通穿过导条，却与定子基波磁动势不能有效耦合，因此表现为转子附加漏感。由于 $$n_+$$ 与 $$n_-$$ 以平方形式出现在式 100 的分母中，增大转子槽数 $$N_R$$ 可减小这一之字形漏项。槽内电压平衡给出折算到定子的转子参数（笔记式 100-101）：

$$R_2 = \frac{12lN_S^2k_S^2}{N_R}R_{slot}$$

$$X_2 = \omega\left[\frac{12lN_S^2k_S^2}{N_R}L_{slot} + \frac{6\mu_0 RlN_S^2k_S^2}{\pi g}\left(\frac{1}{(N_R+p)^2} + \frac{1}{(N_R-p)^2}\right)\right]$$

其中 $$R_{slot}$$、$$L_{slot}$$ 为每单位长度的导条电阻与电感。矩形槽的每单位长度参数为（笔记式 113-114）：

$$R_{slot} = \frac{1}{w_s h_s \sigma}, \qquad L_{slot} = \mu_0\frac{h_s}{3w_s}$$

$$R_2$$ 的表达式可视为槽电阻按 $$12lN_S^2k_S^2/N_R$$ 的比例折算；$$X_2$$ 的第一项为槽漏，第二项为谐波（之字形）漏。

端环电阻修正（笔记式 118）。设端环轴向长度 $$l_r$$、平均宽度 $$w_r$$，假设导条与端环具有相同的径向厚度，则端环损耗与导条损耗之比：

$$\frac{R_{end}}{R_{slot}} = \frac{N_R R w_r}{\pi l l_r p^2}$$

实际设计中端环截面常大于导条截面，使该比值落在 0.1-0.3 量级。

### 3.5 定子漏抗分量

定子漏抗 $$X_1$$ 由多个分量组成，每个分量代表一条不经过转子的磁通路径。

槽漏（slot leakage）：设槽高 $$h$$、槽宽 $$w$$、槽口高 $$d$$、槽口宽 $$u$$、槽长 $$\ell$$，槽磁导为：

$$P = \ell\mu_0\left(\frac{h}{3w} + \frac{d}{u}\right), \qquad L_\ell = PN^2$$

带谐波漏（belt leakage）：由气隙的 5 次与 7 次空间谐波产生，这些谐波与转子耦合，等效为谐波气隙电抗与相应转子谐波阻抗的并联（笔记式 103-108）。

之字形漏（zigzag leakage）：由 $$N_s \pm p$$ 阶谐波产生，这些谐波不被鼠笼短路（笔记式 109）。

斜槽效应（skew）：转子槽沿轴向倾斜电角度 $$\varsigma$$，以减小齿槽锁定（cogging）引起的振动与噪声。斜槽因数：

$$k_{\sigma,n} = \frac{\sin(n\varsigma/2)}{n\varsigma/2}$$

基波互感乘以 $$k_{\sigma}$$，$$X_{ag}(1-k_{\sigma})$$ 表现为串联漏抗（笔记 Figure 5）。

端部漏（end winding leakage）：本质上是三维场问题，常用 Alger 经验式估计（笔记式 4.3.5）：

$$X_e = \frac{14q\mu_0 R N_a^2}{4\pi^2 p^2}(p-0.3)$$

### 3.6 定子绕组电阻

每相绕组总长（含端部）：

$$\ell_w = N_a \cdot 2(\ell + \ell_e)$$

导线截面积由线径与并联股数决定，每相电阻：

$$R_a = \frac{\ell_w}{\sigma A_w}$$

铜电阻随温度修正（Fitzgerald 等教材给出）：

$$R_T = R_t\frac{T_0+T}{T_0+t}$$

铜的 $$T_0 = 234.5$$（IACS 标准电导率 $$5.8\times10^7$$ S/m），电导率为 63% IACS 的铝 $$T_0 \approx 212.9$$。温度修正同样适用于转子导条电阻。

### 3.7 深槽与双鼠笼

起动时转子频率等于定子频率，集肤效应（skin effect）使电流集中在导条顶部，转子电阻增大，起动转矩增大；随转速上升转子频率下降，电流逐渐扩展至整个导条截面，转子电阻回落，运行效率不受影响。这一效果用扩散方程描述。只考虑径向变化与横向磁场（笔记式 4.7）：

$$\frac{\partial^2 H_y}{\partial x^2} = j\omega_s \mu_0 \sigma H_y$$

集肤深度：

$$\delta = \sqrt{\frac{2}{\omega_s \mu_0 \sigma}}$$

矩形深槽的每单位长度阻抗为：

$$Z_{slot} = \frac{1}{w_s \sigma\delta}(1+j)\coth\left((1+j)\frac{h_s}{\delta}\right)$$

$$Z_{slot}$$ 的实部随频率上升、虚部随频率下降，正对应高频高阻、低频低阻的起动-运行需求。深槽的集肤效应可用一个简单图像理解：起动时转子频率高，导条下部被自身电流建立的横向磁场包围，磁通变化在导条内部感应反向电流，把电流推向槽口顶部，等效导电面积变小，电阻升高；进入运行状态后转子频率降到几赫兹量级，集肤深度超过槽深，电流分布接近均匀，电阻回落至直流值。设计上，深槽底部通常较宽、上部较窄（锥形），并可在槽口下方设置窄颈段的高漏感区域，进一步强化起动时电流集中于上部的效果。更复杂的槽形（锥形槽、任意截面）可沿径向分层，用梯形网络逐层递推得到频率相关的槽阻抗 $$Z_s(\omega) = R_s(\omega) + jX_s(\omega)$$（笔记 Figure 8-9），再代入等效电路计算。双鼠笼把这一效果推向极致：上部起动笼（高阻、低漏）与下部运行笼（低阻、高漏）并联（笔记 Figure 10-12）：

```text
        R1        X1
   ────┬──────────┬───────────────────────────────────────
       │          │
       │          │  jXm
       │          │
       │          ├─── X2b ──── R2b/s ────────────────────┐
       │          │                                      │
       │          │                                      │
       │          ├─── X2a ──── R2a/s ───────────────────┘
       │          │
   ────┴──────────┴───────────────────────────────────────
```

其参数由各段几何尺寸折算（笔记式 4.9 节）：

$$R_{2a} = \frac{12lN_S^2k_S^2}{N_R}R_a, \qquad R_{2b} = \frac{12lN_S^2k_S^2}{N_R}R_b$$

起动时高频使电流偏向低漏感的上部笼（$$R_{2b}$$ 主导），获得大起动转矩；额定运行时低频使电流偏向低阻的下部笼（$$R_{2a}$$ 主导），运行损耗低。

### 3.8 损耗、效率与变频运行

感应电机损耗包括：定子铜耗 $$3\lvert\tilde{I}_t\rvert^2R_a$$、转子铜耗 $$sP_{ag}$$、铁心损耗（磁滞与涡流）、摩擦与风阻损耗以及杂散负载损耗。铁心损耗常用经验模型（笔记式 122）：

$$P_d = P_B\left(\frac{\omega_e}{\omega_B}\right)^{\epsilon_f}\left(\frac{B}{B_B}\right)^{\epsilon_b}$$

典型 $$\epsilon_f$$ 介于 1.3 与 1.6 之间，$$\epsilon_b$$ 介于 2.1 与 2.4 之间。气隙、定子齿与定子轭的磁通密度由电压与几何分别计算（笔记式 124-126）。铁心损耗折算为并联在激磁支路上的等效电阻与电抗：

$$r_c = \frac{3\lvert V_a\rvert^2}{P_{core}}, \qquad x_c = \frac{3\lvert V_a\rvert^2}{Q_{core}}$$

效率为输出功率与输入功率之比：

$$\eta = \frac{P_{out}}{P_{in}}$$

机械损耗中，气隙风阻损耗可用库埃特流模型估计，随转速的三次方变化，在窄气隙与高表面速度的高性能机器中不可忽略；冷却风扇的输入功率也计入机械损耗。杂散负载损耗包括转子齿在定子槽口磁通调制下的空载损耗与负载损耗，其作用表现为对转子的制动阻力，应从机械输出中扣除。转子谐波电阻上的功率损耗（带谐波阶次）也被归类为杂散负载损耗，因为它不能由简单等效电路直接算出。

变频运行时，为保持磁通恒定需使电压与频率成正比（恒压频比，volts/Hz）。低于基频时保持恒定磁通与近似恒定转矩；高于基频时电压受限保持恒定，磁通随频率反比下降，临界转矩按频率平方反比下降。忽略定子电阻的理想化模型下，以基频为参考定义绝对转差 $$s_B = \omega_r/\omega_B$$，转矩为（笔记式 6.3）：

$$T_e = \frac{3p}{\omega_B}\frac{\lvert V_0'\rvert^2(R_2/s_B)}{(X_1'+X_2)^2 + (R_2/s_B)^2}$$

其中 $$V_0'$$ 为基频下折算到转子支路前的电压，$$X_1' = X_1 \parallel X_M$$。上式表明恒压频比下转矩只取决于绝对转差（同步转速与实际转速之差），不同频率的转矩-转速曲线为一族平移相同的曲线；超过基频后曲线峰值随频率平方反比衰减（笔记 Figure 14, 17, 18）。

## 四、推导与算例 (Derivations & Examples)

### 4.1 算例一：标准电机的转矩-转速特性

笔记 Table 1 给出一个标准电机的等效电路参数：额定 300 kW、线电压 440 V（相电压 254 V）、$$R_1 = 0.73\ \Omega$$、$$R_2 = 0.64\ \Omega$$、$$X_1 = 0.06\ \Omega$$、$$X_2 = 0.06\ \Omega$$、$$X_M = 2.5\ \Omega$$、同步转速 $$N_s = 1200$$ rpm。60 Hz 下 1200 rpm 对应极对数 $$p = 3$$，同步机械角速度 $$\Omega_s = 2\pi N_s/60 = 125.7$$ rad/s。

按 3.1 节流程计算。以 $$s=0.04$$ 为例：

$$\frac{R_2}{s} = \frac{0.64}{0.04} = 16.0\ \Omega$$

转子支路 $$16.0 + j0.06\ \Omega$$ 与激磁支路 $$j2.5\ \Omega$$ 并联：

$$\tilde{Z}_g = j2.5 \parallel (16.0+j0.06) = 0.381 + j2.439\ \Omega$$

端阻抗与端电流：

$$\tilde{Z}_t = 0.73 + j0.06 + \tilde{Z}_g = 1.111 + j2.499\ \Omega, \qquad I_t = \frac{254}{2.735} = 92.9\ \text{A}$$

转子电流 $$\lvert\tilde{I}_2\rvert = 14.3$$ A，气隙功率与转矩：

$$P_{ag} = 3\times14.3^2\times16.0 = 9.86\ \text{kW}, \qquad T_e = \frac{9.86\times10^3}{125.7} = 78.4\ \text{N·m}$$

对不同转差率重复计算得到转矩-转速数据（表 1）：

| 转差率 $$s$$ | 转速 (rpm) | 转矩 (N·m) | 气隙功率 (kW) | 输入功率 (kW) | 效率 |
|---|---|---|---|---|---|
| 0.04 | 1152 | 78 | 9.9 | 28.7 | 0.33 |
| 0.10 | 1080 | 175 | 22.0 | 41.0 | 0.48 |
| 0.20 | 960 | 292 | 36.7 | 59.3 | 0.50 |
| 0.30 | 840 | 371 | 46.7 | 75.0 | 0.44 |
| 0.50 | 600 | 458 | 57.6 | 100.7 | 0.29 |
| 1.00 | 0 | 500 | 62.8 | 142.6 | 0 |

数值扫描表明临界转矩约 501 N·m，出现在 $$s\approx0.9$$（接近堵转）；机械功率峰值约 33 kW，出现在 $$s\approx0.33$$。该组参数下 $$R_2/(X_1+X_2) = 0.64/0.12 = 5.3$$ 很大，临界转差率超过 1，转矩随转差率单调上升至堵转，与笔记 Figure 3 的曲线形状一致。需要说明：该组参数用于演示等效电路计算流程与曲线形状，标称的 300 kW 额定功率不能由该电路在合理转差率下达到；其每单位定子电阻偏大，效率峰值约 50%。

在 $$s=0.1$$ 处计算功率因数：

$$\cos\psi = \frac{P_{in}}{3V_t I_t} = \frac{41.0\times10^3}{3\times254\times93.3} = 0.577$$

### 4.2 算例二：从尺寸出发的设计评估

按 3.2 节流程评估一台小型 4 极（$$p=2$$）、60 Hz、三相感应电机。给定：定子内径半径 $$R = 0.055$$ m、有效长度 $$l = 0.09$$ m、有效气隙 $$g = 0.35$$ mm；定子每相串联匝数 $$N_S = 120$$、绕组因数 $$k_S = 0.94$$；鼠笼转子 $$N_R = 24$$ 根铝导条，截面宽 $$w_s = 5$$ mm、高 $$h_s = 15$$ mm，铝电导率 $$\sigma = 3.5\times10^7$$ S/m；端环轴向长度 $$l_r = 30$$ mm、平均宽度 $$w_r = 12$$ mm。

第一步，气隙磁导：

$$\wp_{ag} = \frac{4\mu_0 R l}{\pi p^2 g} = \frac{4\times4\pi\times10^{-7}\times0.055\times0.09}{\pi\times4\times3.5\times10^{-4}} = 5.66\times10^{-6}\ \text{H}$$

激磁电抗：

$$X_M = \frac{3}{2}\omega\wp_{ag}N_S^2k_S^2 = 1.5\times377\times5.66\times10^{-6}\times120^2\times0.94^2 = 40.7\ \Omega$$

第二步，导条每单位长度参数：

$$R_{slot} = \frac{1}{w_s h_s \sigma} = \frac{1}{0.005\times0.015\times3.5\times10^7} = 3.81\times10^{-4}\ \Omega/\text{m}$$

$$L_{slot} = \mu_0\frac{h_s}{3w_s} = 1.26\times10^{-6}\ \text{H/m}$$

折算系数 $$12lN_S^2k_S^2/N_R = 12\times0.09\times120^2\times0.94^2/24 = 571.6$$。转子电阻与漏抗：

$$R_2 = 571.6\times3.81\times10^{-4} = 0.218\ \Omega$$

$$X_2 = \omega\left(571.6\times1.26\times10^{-6} + \frac{6\mu_0 RlN_S^2k_S^2}{\pi g}\left[\frac{1}{(24+2)^2}+\frac{1}{(24-2)^2}\right]\right) = 0.271 + 0.577 = 0.849\ \Omega$$

端环修正：

$$\frac{R_{end}}{R_{slot}} = \frac{N_R R w_r}{\pi l l_r p^2} = \frac{24\times0.055\times0.012}{\pi\times0.09\times0.03\times4} = 0.467$$

$$R_2 = 0.218\times(1+0.467) = 0.320\ \Omega$$

第三步，定子电阻。每相导线总长 $$\ell_w = 120\times2\times(0.09+0.12) = 50.4$$ m，铜导线截面积 $$A_w = 2.5\times10^{-6}$$ m²，铜电导率 $$\sigma_{cu} = 5.8\times10^7$$ S/m：

$$R_1 = \frac{50.4}{5.8\times10^7\times2.5\times10^{-6}} = 0.348\ \Omega$$

定子槽漏与端部漏按 3.5 节方法估算，合计约 $$X_1 \approx 1.2\ \Omega$$。

第四步，性能。线电压 220 V（相电压 $$V_t = 127$$ V），取额定转差率 $$s = 0.05$$：

$$\frac{R_2}{s} = \frac{0.320}{0.05} = 6.40\ \Omega, \qquad \tilde{Z}_g = j40.7\parallel(6.4+j0.849) = 6.00 + j1.76\ \Omega$$

$$\tilde{Z}_t = 0.348 + j1.2 + \tilde{Z}_g = 6.35 + j2.96\ \Omega$$

$$\lvert\tilde{I}_t\rvert = 18.2\ \text{A}, \qquad \lvert\tilde{I}_2\rvert = 17.6\ \text{A}$$

$$P_{ag} = 3\times17.6^2\times6.40 = 5.93\ \text{kW}, \qquad P_m = 5.93\times0.95 = 5.63\ \text{kW}$$

$$T_e = \frac{P_{ag}p}{\omega} = \frac{5.93\times10^3\times2}{377} = 31.5\ \text{N·m}$$

$$P_{in} = 5.93 + 3\times18.2^2\times0.348 = 6.27\ \text{kW}$$

设铁心损耗约 200 W、摩擦风阻 50 W，则轴输出为 $$5.63-0.05 = 5.58$$ kW，效率：

$$\eta = \frac{5.58}{6.27+0.2} = 0.86$$

功率因数：

$$\cos\psi = \frac{P_{in}}{3V_t I_t} = \frac{6.27\times10^3}{3\times127\times18.2} = 0.91$$

设计评估结果表明，该机器在 $$s=0.05$$ 处输出约 5.6 kW、转矩约 31 N·m、效率约 86%，是一台合理的 5.5 kW 级电机。若输出不足或效率不达标，可调整导条截面、气隙或匝数后重算。深槽与双鼠笼设计（3.7 节）不改变额定点计算流程，只改变 $$R_2$$、$$X_2$$ 随频率的变化关系。

## 五、核心 Takeaway (Takeaways)

1. 感应电机靠旋转定子场在转子中感应电流产生转矩，电动机运行必然低于同步转速。转差率 $$s = 1 - p\omega_m/\omega$$ 同时决定转子频率与转子铜耗 $$sP_{ag}$$，是感应电机分析的核心变量。
2. 折算后的每相等效电路由 $$R_a$$、$$X_1$$、$$X_M$$、$$X_2$$、$$R_2/s$$ 组成。$$R_2/s$$ 上的功率即气隙功率，机械功率为 $$(1-s)P_{ag}$$，转矩为 $$T_e = 3p\lvert\tilde{I}_2\rvert^2 R_2/(s\omega)$$。
3. 简化电路下临界转矩与转子电阻无关，临界转差率与转子电阻成正比。绕线转子串电阻起动与深槽、双鼠笼设计都利用了这一关系，在不牺牲运行效率的前提下提高起动转矩。
4. 解析设计评估从尺寸与材料出发：气隙磁导与卡特系数给出激磁电抗，槽与端部几何给出漏抗，导条截面给出转子电阻，端环修正后折算到定子，最后在额定转差率处计算性能。
5. 恒压频比运行时转矩只取决于绝对转差，低于基频近似恒定转矩，高于基频临界转矩按频率平方反比下降，这为变频调速与磁场定向控制提供了基础。
