> 原课程: MIT 6.685 — Electric Machines, Fall 2013 (James L. Kirtley Jr.)

## 一、本章概要 (Overview)

绕组电感 (winding inductance) 是电机建模的核心量。电机的电压方程写成电压等于磁链 (flux linkage) 变化率的形式：

$$\vec{v} = \frac{d\vec{\lambda}}{dt}$$

而每一相绕组的磁链又由全部绕组的电流共同决定，即自感 (self inductance) 与互感 (mutual inductance) 的线性组合。转矩的表达式同样依赖电感：在磁场能量方法中，转矩等于磁场共能 (coenergy) 对转子位置角的偏导。因此，只要掌握了各绕组电感的数值及其随转子位置的变化规律，就可以完整写出电机的电压方程与转矩表达式。本章的目的，就是在圆转子 (round rotor)、窄气隙的假设下，从绕组的几何布置出发，把自感与互感逐一计算出来。

本章的核心思想可以概括为两点。第一，空间分布 (distributed) 的绕组在气隙中产生近似正弦分布的磁动势 (mmf) 波；绕组沿圆周铺开得越均匀、线圈跨距越接近整距，磁动势波越接近理想正弦，空间谐波越小。第二，两个绕组磁轴 (magnetic axis) 之间的夹角决定了它们的互感大小；转子旋转时，定子相绕组与转子励磁绕组 (field winding) 磁轴的相对位置随之变化，互感按夹角的余弦规律变化，这一位置依赖性正是电机产生转矩的来源。

本章的适用范围与假设如下：只处理理想化的气隙磁场，不考虑槽漏抗 (slot reactance)、端部绕组 (end winding)、周边漏抗与斜槽 (skew) 电抗；但保留绕组磁动势的空间谐波 (space harmonic)，因为谐波对电感与谐波转矩均有影响。

与前后章节的关系：第 3 章建立了同步电机的电压方程与相量图模型，其中把同步电抗 $$X_d$$ 视为已知参数；本章从绕组的物理结构出发，给出 $$X_d$$ 及其背后电感矩阵的推导。本章得到的结论在后续章节被反复使用：励磁绕组与电枢绕组之间的互感余弦规律构成同步电机转矩的基础，三相电感矩阵与 dq0 变换（派克变换）则是感应电机与同步电机暂态分析的标准工具。第 5 章将把这些结果应用到直流与永磁电机。

## 二、物理机制与数学推导 (Physics & Math Derivation)

### 2.1 定子结构与绕组布置

图 1 给出了一个十二槽定子的轴向截面示意。实际展示的是用于构成磁路的一片薄钢片，即叠片 (lamination) 的形状。铁心用薄片叠加是为了抑制涡流损耗；在 60 Hz 工频下，叠片厚度通常为 0.355 mm。绕组安置在定子槽 (slot) 中，槽与槽之间是齿 (tooth)。梯形槽与相对窄的槽口 (slot depression) 区域配合，可以改善气隙磁场的均匀性、提高气隙磁导，并帮助固定绕组。

图 2 展示了把槽齿区域"拉直"后的绕组布置，这是一个三相、两极、十二槽的整距 (full-pitched) 绕组。整距绕组的每一线圈跨过恰好一个极距：例如 A 相的一个线圈跨在槽 1 与槽 7 之间（相距六个槽），即 180° 电角度。整距绕组端部较长，空间谐波较大，实际电机很少采用。图 3 展示的是短距 (short-pitched) 绕组，每相由四个线圈组成，A 相四个线圈分别跨在槽 1 与 6、槽 2 与 7、槽 7 与 12、槽 8 与 1 之间。每个跨距为五个槽，因此称为"六分之五节距"（5/6 pitch）。短距能缩短端部绕组长度并削弱空间谐波。这个示例定子既有分布（每极每相多于一个槽），又涉及绕组节距，后续的小节将给出估算气隙磁场与电感的统一方法。

### 2.2 整距集中绕组的磁动势与气隙磁场

从最简单的情形出发：一个整距集中绕组，总匝数为 $$N$$，分布在 $$p$$ 个极对数上，通入电流 $$I$$。图 4 展示了这一原始几何问题。忽略铁心中的磁压降，把磁动势全部消耗在气隙上，则绕组的磁动势沿圆周是一个幅值为 $$NI/(2p)$$ 的方波（在每极上电流建立 $$NI/(2p)$$ 安匝）。把这个方波做傅里叶展开，得到：

$$F = -\sum_{n=1,3,5,\ldots}^{\infty} \frac{4}{n\pi}\frac{NI}{2p}\sin(np\theta)$$

其中 $$n$$ 为空间谐波阶数，只有奇数阶存在。幅值 $$(4/\pi)(NI/(2p))$$ 来自方波的基本分量。图 5 展示了这一磁动势随角度 $$\theta$$ 的分布。式中的负号来源于相位参考的选取。

在窄气隙近似下，气隙磁通密度 (magnetic flux density) 与磁动势成正比：

$$B_r = -\sum_{n=1,3,5,\ldots}^{\infty} \frac{\mu_0}{g}\frac{4}{n\pi}\frac{NI}{2p}\sin(np\theta)$$

其中 $$g$$ 为气隙长度，$$\mu_0$$ 为真空磁导率，$$B_r$$ 为径向磁通密度分量。这一关系来自磁路欧姆定律：气隙磁压降等于磁动势，即 $$B_r g/\mu_0 = F$$。

真实绕组通常既非整距也非集中，其磁动势和所交链的磁通都要用一个绕组因数 (winding factor) 修正，绕组因数等于节距因数与分布因数的乘积，将在 2.6 与 2.7 节推导。

### 2.3 三相电流与旋转磁场

现在考虑一个三相绕组，通入平衡电流：

$$I_a = I\cos\omega t, \qquad I_b = I\cos\left(\omega t - \frac{2\pi}{3}\right), \qquad I_c = I\cos\left(\omega t + \frac{2\pi}{3}\right)$$

把三相各自的磁场叠加。设三相磁轴在空间上相隔 $$2\pi/3$$ 电角度，即相隔 $$2\pi/(3p)$$ 机械角度。利用三角恒等式，把第 $$i$$ 相的瞬时磁场写成两个行波的叠加：

$$\cos(\omega t - \varphi_i)\sin(np\theta - n\xi_i) = \frac{1}{2}\left[\sin(np\theta + \omega t - (n\xi_i + \varphi_i)) + \sin(np\theta - \omega t - (n\xi_i - \varphi_i))\right]$$

其中 $$\varphi_i$$ 为该相电流的相位（$$0$$、$$-2\pi/3$$、$$+2\pi/3$$），$$\xi_i$$ 为该相磁轴的机械角度。把三项求和。对于前向行波项 $$\sin(np\theta + \omega t)$$，第 $$b$$、$$c$$ 相的相角分别为 $$2\pi(n-1)/3$$ 与 $$2\pi(2n+1)/3$$；当 $$n = 1, 7, 13, \ldots$$ 时三相同相，前向行波增强；当 $$n$$ 为三的倍数时三相相角之和为 $$2\pi$$ 的整数倍分布，恰好抵消。对于后向行波项 $$\sin(np\theta - \omega t)$$，相角分布相反：当 $$n = 5, 11, \ldots$$ 时三相同相，后向行波增强。于是平衡三相电流产生的气隙磁场为：

$$B_r = \sum_{n} B_{rn}\sin(np\theta \mp \omega t)$$

其中上面一组符号（减号）对应 $$n = 1, 7, \ldots$$，下面一组符号（加号）对应 $$n = 5, 11, \ldots$$，其余谐波项为零；各谐波幅值为：

$$B_{rn} = \frac{3}{2}\frac{\mu_0}{g}\frac{4}{n\pi}\frac{NI}{2p}$$

这一结果是电机学的核心：平衡三相电流在气隙中建立基波旋转磁场，基波转速为 $$\omega/p$$；$$n = 5, 11$$ 等谐波构成反向旋转的磁场，是三的倍数阶谐波（$$n = 3, 9, \ldots$$）在平衡运行中被消除。每个相绕组本身的磁场幅值为单相值，但三相叠加后幅值变成单相值的 $$3/2$$ 倍，这正是同步电感中 $$3/2$$ 因子的来源。

另一种激励方式是零序电流 (zero-sequence current)：

$$I_a = I_b = I_c = I\cos\omega t$$

把三相磁场叠加，只有三的倍数阶谐波（$$n = 3, 9, \ldots$$）彼此同相而保留，其余谐波抵消。注意到 $$(3/2)(\sin(np\theta - \omega t) + \sin(np\theta + \omega t)) = 3\sin(np\theta)\cos(\omega t)$$，零序情形下的气隙磁场为：

$$B_r = \sum_{n=3,9,\ldots}^{\infty} \frac{\mu_0}{g}\frac{4}{n\pi}\frac{NI}{2p}\cdot\frac{3}{2}\left[\sin(np\theta - \omega t) + \sin(np\theta + \omega t)\right]$$

零序磁场是三的倍数阶谐波的驻波，幅值为单相值的 3 倍，随频率 $$f$$ 脉振而不旋转。

### 2.4 磁链与电感的一般表达式

为了由气隙磁场求电感，先计算单个整距线圈交链的磁通。设气隙磁通密度具有如下一般形式：

$$B_r = \sum_{n=1}^{\infty} B_{rn}\sin(np\theta \pm \omega t)$$

一个单匝、整距、跨过一对极的线圈，其交链磁通为对线圈跨距的积分：

$$\Phi = \int_{0}^{\pi/p} B_r R l\, d\theta$$

把磁场表达式代入，对第 $$n$$ 阶谐波：

$$\Phi_n = B_{rn} R l \int_{0}^{\pi/p} \sin(np\theta \pm \omega t)\, d\theta = \frac{2Rl}{np} B_{rn}\cos(\omega t)$$

其中用到了 $$n$$ 为奇数时 $$\cos(n\pi \pm \omega t) = -\cos(\omega t)$$。于是单匝整距线圈交链的总磁通为：

$$\Phi = 2Rl\sum_{n=1}^{\infty} \frac{B_{rn}}{np}\cos(\omega t)$$

匝数为 $$N$$ 的绕组交链的磁链为：

$$\lambda = N\Phi$$

由此，自感等于绕组自身电流产生的磁链与电流之比，互感等于另一个绕组电流在本绕组中产生的磁链与电流之比。电感的一切计算都归结为：由电流求气隙磁场，由磁场求磁链，再由磁链除以电流。

### 2.5 绕组因数：定义与互易性

真实绕组既非整距也非集中。最简洁的处理方式是引入绕组因数 (winding factor) $$k_w$$，定义为实际绕组交链的磁链与同匝数整距集中绕组交链磁链之比：

$$k_w = \frac{\lambda_{\text{actual}}}{\lambda_{\text{full-pitch}}}$$

由互易性 (reciprocity) 论证可以证明，绕组因数同时也是实际绕组产生的有效磁动势与同一绕组在整距集中布置下产生的磁动势之比。论证要点如下：任意两绕组之间的互感是互易的，即绕组 1 对绕组 2 的互感等于绕组 2 对绕组 1 的互感。每个绕组都有影响其交链磁链的绕组因数，而互感又必须互易，因此同一个绕组因数也必然作用于该绕组产生的磁动势。这样，只需一次计算绕组因数，就同时修正了磁场与磁链两端的效应。

绕组因数通常对每个空间谐波分别给出。对于常规绕组，绕组因数等于节距因数与分布因数的乘积：

$$k_w = k_p k_b$$

下面两节分别推导这两个因数。

### 2.6 节距因数

设气隙磁通密度为单一行波：

$$B_r = B_n\sin(np\theta - \omega t)$$

考虑一个节距为 $$\alpha$$（以电角度计的线圈两边之间的角位移）的短距线圈，其跨距中点仍对准该极的中心。整距对应 $$\alpha = \pi$$。线圈交链的磁通为（参见图 6）：

$$\lambda = Nl\int_{\frac{\pi}{2p}-\frac{\alpha}{2p}}^{\frac{\pi}{2p}+\frac{\alpha}{2p}} B_n\sin(np\theta - \omega t)R\, d\theta$$

积分得到：

$$\lambda = \frac{2NlRB_n}{np}\sin\left(\frac{n\pi}{2}\right)\sin\left(\frac{n\alpha}{2}\right)$$

其中第二个正弦因子来自积分限在中心点两侧的对称偏移。与整距线圈（$$\alpha = \pi$$）交链的磁链相比，第 $$n$$ 阶谐波的节距因数 (pitch factor) 为：

$$k_{pn} = \sin\left(\frac{n\alpha}{2}\right)$$

对于基波，整距时 $$k_{p1} = 1$$；短距使基波磁链略有减小，同时大幅削弱谐波分量。例如 5/6 节距下基波节距因数为 $$\sin(5\pi/12) \approx 0.966$$，而三次谐波因数的幅值为 $$\lvert \sin(3\alpha/2) \rvert = \lvert \sin(5\pi/4) \rvert \approx 0.707$$，其他谐波削减更显著。

### 2.7 分布因数

分布因数描述绕组由多个线圈组成、各线圈交链的磁通彼此存在相位差这一事实。设一个常规绕组由 $$m$$ 个线圈单元组成，相邻线圈单元相隔电角度 $$\gamma$$（图 7）。一个一边位于角度 $$\xi$$ 的整距线圈，在磁场 (19) 下交链的磁通为：

$$\lambda = Nl\int_{\xi/p}^{\pi/p - \xi/p} B_n\sin(np\theta - \omega t)R\, d\theta$$

积分为：

$$\lambda = \frac{2NlRB_n}{np}\operatorname{Re}\left\{e^{j(\omega t - n\xi)}\right\}$$

其中引入了复数记号以方便后续求和。各线圈交链的磁通相位不同，矢量叠加如图 8 所示。

若绕组分布在 $$m$$ 组槽中且槽距均匀，第 $$i$$ 个槽的位置为：

$$\xi_i = i\gamma - \frac{m-1}{2}\gamma$$

每槽匝数为 $$N/(mp)$$，实际交链的总磁链为：

$$\lambda = \frac{2NlRB_n}{np}\cdot\frac{1}{m}\sum_{i=0}^{m-1}\operatorname{Re}\left\{e^{j(\omega t - n\xi_i)}\right\}$$

于是第 $$n$$ 阶谐波的分布因数 (breadth factor) 为：

$$k_{bn} = \frac{1}{m}\sum_{i=0}^{m-1}e^{-jn\left(i\gamma - \frac{m-1}{2}\gamma\right)}$$

提取公因子后：

$$k_{bn} = \frac{e^{jn\gamma(m-1)/2}}{m}\sum_{i=0}^{m-1}e^{-jni\gamma}$$

利用有限几何级数求和公式：

$$\sum_{i=0}^{m-1}e^{-jni\gamma} = \frac{1-e^{-jnm\gamma}}{1-e^{-jn\gamma}}$$

把分子分母分别写成指数形式并整理，公共相位因子 $$e^{-jn\gamma/2}$$ 归一化后，得到：

$$k_{bn} = \frac{\sin\left(\frac{nm\gamma}{2}\right)}{m\sin\left(\frac{n\gamma}{2}\right)}$$

这就是分布因数的标准形式。上述推导还可从几何角度验证（图 9）：把各线圈电压（磁链）表示为矢量，短矢量首尾相接。设单个线圈矢量为 $$F_1$$，合成矢量为 $$F$$，各矢量中垂线交于 $$O$$ 点，则：

$$\frac{F}{2} = OA\sin\left(\frac{m\gamma}{2}\right), \qquad \frac{F_1}{2} = OA\sin\left(\frac{\gamma}{2}\right)$$

消去 $$OA$$，得到合成矢量：

$$F = mF_1\frac{\sin\left(\frac{m\gamma}{2}\right)}{m\sin\left(\frac{\gamma}{2}\right)}$$

分布因数即为 $$F/(mF_1)$$，与解析结果一致。分布越宽（$$m$$ 越大），基波因数越小、谐波抑制越强，这是电机设计中选择槽数的依据之一。

### 2.8 同步电感、零序电感与励磁互感

把磁链公式与绕组因数结合起来，即可写出各类电感。三相绕组通入平衡电流 (3) 时，某一相的表观电感称为同步电感 (synchronous inductance)：

$$L_d = \sum_{n=1,5,7,\ldots}^{\infty} \frac{3}{2}\cdot\frac{4}{\pi}\frac{\mu_0 N^2 Rl\,k_{wn}^2}{p^2 g n^2}$$

其中求和覆盖除三的倍数阶之外的所有奇数谐波，$$k_{wn}$$ 为第 $$n$$ 阶谐波的绕组因数，$$R$$ 为气隙半径，$$l$$ 为铁心长度。该表达式是近似的，因为它忽略了高阶谐波与转子之间的异步相互作用。$$3/2$$ 因子来自平衡三相电流建立的旋转磁场：基波场幅值是单相值的 1.5 倍。

绕组通入零序电流 (4) 时，磁链与电流之比为零序电感 (zero-sequence inductance)。零序磁场只含三的倍数阶谐波且幅值为单相值的 3 倍，因此：

$$L_0 = \sum_{n=3,9,\ldots}^{\infty} 3\cdot\frac{4}{\pi}\frac{\mu_0 N^2 Rl\,k_{wn}^2}{p^2 g n^2}$$

励磁绕组与电枢绕组之间的互感随转子位置角 $$\phi$$ 变化：

$$M(\phi) = \sum_{n=1,3,5,\ldots}^{\infty} \frac{4}{\pi}\frac{\mu_0 N_f N_a k_{fn} k_{an} Rl}{p^2 g n^2}\cos(np\phi)$$

其中 $$N_f$$、$$N_a$$ 分别为励磁与电枢绕组的匝数，$$k_{fn}$$、$$k_{an}$$ 为各自绕组因数。$$\phi$$ 为转子位置（励磁磁轴与电枢磁轴的机械夹角）。

### 2.9 互感的余弦规律

两个磁轴夹角为 $$\theta$$（机械角）的绕组，其互感的一般表达式为：

$$M_{12} = \sum_{n=1,3,5,\ldots}^{\infty} \frac{4}{\pi}\frac{\mu_0 N_1 N_2 k_{1n} k_{2n} Rl}{p^2 g n^2}\cos(np\theta)$$

对基波（$$n = 1$$）只保留这一项，互感简化为余弦规律：

$$M_{12} = M\cos(p\theta)$$

其中 $$M = \frac{4}{\pi}\frac{\mu_0 N_1 N_2 k_{1} k_{2} Rl}{p^2 g}$$。若以电角度表示轴间夹角，则 $$M_{ab} = M\cos\theta$$。这一余弦规律解释了转子旋转如何调制定子与转子绕组之间的耦合：转子每转一个电角度，励磁绕组与某一定子相之间的互感就按该角度的余弦变化。同步电机的电压方程中，电枢绕组磁链包含 $$M\cos(p\phi)\,i_f$$ 项，转子转速为 $$\omega_m = \omega/p$$ 时 $$p\phi = \omega t$$，互感按电源频率脉振。

### 2.10 凸极机：电感的双倍角规律

以上均假设气隙均匀（圆转子）。凸极 (salient-pole) 电机气隙随转子位置变化：转子直轴 (direct axis) 对准某定子相绕组时，该相的气隙磁导最大、自感最大；转子交轴 (quadrature axis) 对准时气隙最大、磁导与自感最小。转子每转过一个极距（电角度 $$180°$$，即 $$\pi$$），气隙几何恢复原状，因此气隙磁导按两倍电角度变化。定子相自感因而具有双倍角形式：

$$L_{aa}(\theta) = L_0 + L_2\cos 2\theta$$

其中 $$\theta$$ 为电角度转子位置，$$L_0$$ 为平均值，$$L_2$$ 为波动幅值。同理，两定子相之间的互感也含双倍角项，而励磁与电枢之间的互感仍按单倍角余弦变化（基波）。若直轴与交轴分别对应自感 $$L_d$$ 与 $$L_q$$，则有：

$$L_0 = \frac{L_d + L_q}{2}, \qquad L_2 = \frac{L_d - L_q}{2}$$

$$L_2$$ 的存在意味着即使没有励磁电流，绕组自感也随转子位置变化，从而产生磁阻转矩 (reluctance torque)，这是磁阻电机运行的基础。

## 三、模型与方法精解 (Models & Methods)

### 3.1 三相电感矩阵（含励磁绕组）

把各绕组的自感与互感汇总，可写出完整的电感矩阵。对于带励磁绕组的圆转子电机，忽略高于基波的空间谐波，取定子每相自感为 $$L_s$$（含气隙分量与漏分量），两相定子绕组磁轴相隔 $$120°$$ 电角度，互感为：

$$M_s = -\frac{1}{2}L_{\text{ag}}$$

其中 $$L_{\text{ag}}$$ 为定子相绕组的纯气隙自感，$$L_s = L_{\text{ag}} + L_l$$，$$L_l$$ 为漏感。励磁绕组与三相之间的互感为 $$M\cos(p\phi)$$、$$M\cos(p\phi - 2\pi/3)$$、$$M\cos(p\phi + 2\pi/3)$$。于是磁链方程为：

$$\begin{bmatrix}\lambda_a\\\lambda_b\\\lambda_c\\\lambda_f\end{bmatrix} = \begin{bmatrix}L_s & -M_s & -M_s & M\cos p\phi\\-M_s & L_s & -M_s & M\cos(p\phi - 2\pi/3)\\-M_s & -M_s & L_s & M\cos(p\phi + 2\pi/3)\\M\cos p\phi & M\cos(p\phi - 2\pi/3) & M\cos(p\phi + 2\pi/3) & L_f\end{bmatrix}\begin{bmatrix}i_a\\i_b\\i_c\\i_f\end{bmatrix}$$

矩阵结构具有对称性：定子三相块在平衡圆转子情形下对角线为 $$L_s$$、非对角线为 $$-M_s$$，只含常数；转子块与耦合块的对角线为常数 $$L_f$$，耦合块随转子位置 $$p\phi$$ 变化。若去掉励磁绕组一行一列，就得到三相定子自感互感矩阵：

$$\begin{bmatrix}\lambda_a\\\lambda_b\\\lambda_c\end{bmatrix} = \begin{bmatrix}L_s & -M_s & -M_s\\-M_s & L_s & -M_s\\-M_s & -M_s & L_s\end{bmatrix}\begin{bmatrix}i_a\\i_b\\i_c\end{bmatrix}$$

这一矩阵的全部元素为常数，是圆转子三相绕组在静止坐标下的特征。对凸极机，矩阵中的常数元素将代之以含 $$\cos 2\theta$$ 的项，耦合元素保持单倍角余弦形式。

### 3.2 位置相关电感与转矩

电压方程与转矩都源于电感矩阵的位置依赖性。对线性磁路，磁场共能为：

$$W_c = \frac{1}{2}\sum_{i}\sum_{j} L_{ij}(\theta)\, i_i i_j$$

转矩等于共能对机械角位置 $$\theta_m$$ 的偏导（电流保持不变）：

$$T = \frac{\partial W_c}{\partial \theta_m} = \frac{1}{2}\sum_{i}\sum_{j} i_i i_j \frac{dL_{ij}}{d\theta_m}$$

把该式应用到互感项 $$M\cos(p\theta_m)\,i_f i_a$$，得：

$$T = -p M\,i_f i_a\sin(p\theta_m)$$

若 $$i_a = I_a\cos(\omega t)$$，转子以同步速旋转使 $$p\theta_m = \omega t + \delta$$，则瞬时转矩在一个周期内的平均值为：

$$T_{\text{avg}} = -\frac{p M I_f I_a}{2}\sin\delta$$

这就是同步电机的稳态转矩（功角特性），$$\delta$$ 为功角，与第 3 章同步电机模型中的结果一致。自感项 $$L_2\cos 2\theta$$ 产生磁阻转矩：

$$T_{\text{rel}} = \frac{1}{2}i_a^2\frac{d}{d\theta_m}\left(L_2\cos 2\theta\right) = -p L_2 i_a^2\sin 2\theta$$

磁阻转矩随两倍电角度变化，其平均值在适当的电流相位下非零，构成磁阻电机与凸极同步电机的附加转矩分量。

### 3.3 与 dq0 变换的连接

静止三相坐标下的电感矩阵（尤其凸极机）包含随转子位置变化的项，直接求解电压方程十分不便。dq0 变换（派克变换，Park transform）把三相电量变换到与转子同步旋转的参考坐标系：

$$\begin{bmatrix}v_d\\v_q\\v_0\end{bmatrix} = \frac{2}{3}\begin{bmatrix}\cos\theta & \cos(\theta - 2\pi/3) & \cos(\theta + 2\pi/3)\\-\sin\theta & -\sin(\theta - 2\pi/3) & -\sin(\theta + 2\pi/3)\\1/2 & 1/2 & 1/2\end{bmatrix}\begin{bmatrix}v_a\\v_b\\v_c\end{bmatrix}$$

在旋转坐标系中观察，定子绕组表现为直轴绕组与交轴绕组，其自感退化为常数 $$L_d$$ 与 $$L_q$$（圆转子时 $$L_d = L_q$$），零轴对应零序电感 $$L_0$$。位置相关的电感矩阵被对角化为常数矩阵，电压方程变为常系数微分方程，这是后续感应电机与同步电机动态分析的标准工具。因此，本章推导的 $$L_d$$、$$L_0$$、$$M$$ 等量正是 dq0 模型中的参数来源。

## 四、推导与算例 (Derivations & Examples)

### 4.1 算例一：5/6 节距、每极每相两槽绕组的绕组因数

考虑一个三相、两极（$$p = 1$$）、十二槽的定子，采用 5/6 节距，每极每相两个槽。槽距角为 $$30°$$ 电角度，即 $$\gamma = \pi/6$$；每个相带内 $$m = 2$$ 个线圈单元。

节距因数（基波）：$$\alpha = 5\pi/6$$：

$$k_{p1} = \sin\left(\frac{\alpha}{2}\right) = \sin\left(\frac{5\pi}{12}\right) \approx 0.966$$

分布因数（基波）：

$$k_{b1} = \frac{\sin\left(\frac{m\gamma}{2}\right)}{m\sin\left(\frac{\gamma}{2}\right)} = \frac{\sin(\pi/6)}{2\sin(\pi/12)} = \frac{0.5}{2 \times 0.2588} \approx 0.966$$

绕组因数：

$$k_{w1} = k_{p1}k_{b1} \approx 0.966 \times 0.966 \approx 0.933$$

对照三次谐波：$$k_{p3} = \sin(3\alpha/2) = \sin(5\pi/4)$$，幅值为 0.707；$$k_{b3} = \frac{\sin(3m\gamma/2)}{m\sin(3\gamma/2)} = \frac{\sin(\pi/2)}{2\sin(\pi/4)} \approx 0.707$$；$$k_{w3} \approx 0.707 \times 0.707 \approx 0.5$$。基波因数接近 1 而三次谐波因数降至 0.5，体现了短距与分布对谐波的抑制作用。

### 4.2 算例二：同步电感与励磁互感数值

设上述绕组用于一台圆转子同步机：每相匝数 $$N = 100$$，励磁绕组匝数 $$N_f = 200$$，气隙半径 $$R = 0.1$$ m，铁心长度 $$l = 0.2$$ m，气隙长度 $$g = 1$$ mm，基波绕组因数 $$k_{w1} = 0.933$$。

只保留基波，同步电感为：

$$L_d = \frac{3}{2}\cdot\frac{4}{\pi}\cdot\frac{\mu_0 N^2 Rl\,k_{w1}^2}{p^2 g} = \frac{3}{2}\cdot\frac{4}{\pi}\cdot\frac{4\pi\times10^{-7}\times 10^{4}\times 0.02\times 0.933^2}{0.001} \approx 0.42\ \text{H}$$

励磁与电枢的互感幅值为：

$$M = \frac{4}{\pi}\cdot\frac{\mu_0 N_f N_a k_{f1}k_{a1} Rl}{p^2 g} = \frac{4}{\pi}\cdot\frac{4\pi\times10^{-7}\times 200\times 100\times 0.02\times 0.933^2}{0.001} \approx 0.56\ \text{H}$$

励磁绕组自感（气隙分量）为：

$$L_f = \frac{4}{\pi}\cdot\frac{\mu_0 N_f^2 Rl\,k_{f1}^2}{p^2 g} \approx 1.11\ \text{H}$$

数值很大是因为磁化电感按 $$N^2/g$$ 增长：匝数多、气隙窄，故基波磁化电感在亨利量级。实际电机中还需加上漏感（每相约百分之几到百分之十几），并在饱和时按磁化曲线修正。

### 4.3 算例三：凸极机的 L0、L2 与磁阻转矩

同一台电机的凸极版本，设直轴与交轴电感分别为 $$L_d = 0.42$$ H、$$L_q = 0.18$$ H。则：

$$L_0 = \frac{L_d + L_q}{2} = 0.30\ \text{H}, \qquad L_2 = \frac{L_d - L_q}{2} = 0.12\ \text{H}$$

该台电机每相自感随转子位置变化：$$L_{aa}(\theta) = 0.30 + 0.12\cos 2\theta$$。通入 $$i_a = 10$$ A 时，磁阻转矩的瞬时峰值：

$$T_{\text{rel,peak}} = p L_2 i_a^2 = 1 \times 0.12 \times 100 = 12\ \text{N}\cdot\text{m}$$

励磁电流 $$i_f = 10$$ A、电枢电流幅值 $$I_a = 10$$ A 时，同步转矩的平均峰值为：

$$T_{\text{avg,peak}} = \frac{p M I_f I_a}{2} = \frac{0.56 \times 100}{2} = 28\ \text{N}\cdot\text{m}$$

对比可见，在相同的电流水平下，由互感产生的主转矩显著大于单相磁阻转矩。凸极机的附加磁阻转矩在无励磁（磁阻电机）运行时成为主转矩来源。

## 五、核心 Takeaway (Takeaways)

1. 分布绕组在气隙中产生近似正弦的磁动势波，其基波幅值为 $$(4/\pi)(NI/2p)$$，气隙磁通密度为 $$B_r = \mu_0 F/g$$。绕组的实际磁场与磁链用绕组因数 $$k_w = k_p k_b$$ 修正。
2. 平衡三相电流建立旋转磁场：基波与 $$n = 1, 7, \ldots$$ 阶谐波前向旋转，$$n = 5, 11, \ldots$$ 阶谐波后向旋转，三的倍数阶谐波被消除；旋转磁场使电感的 $$3/2$$ 因子出现。零序电流只产生三的倍数阶谐波驻波。
3. 电感由磁链公式 $$\lambda = N\Phi$$ 计算：同步电感 $$L_d = \sum \frac{3}{2}\cdot\frac{4}{\pi}\frac{\mu_0 N^2 Rl k_{wn}^2}{p^2 g n^2}$$，零序电感 $$L_0 = \sum 3\cdot\frac{4}{\pi}\frac{\mu_0 N^2 Rl k_{wn}^2}{p^2 g n^2}$$，励磁互感 $$M(\phi) = \sum \frac{4}{\pi}\frac{\mu_0 N_f N_a k_{fn}k_{an} Rl}{p^2 g n^2}\cos(np\phi)$$。
4. 两绕组互感随其磁轴夹角按余弦变化：圆转子基波 $$M_{ab} = M\cos\theta$$，定子相与转子励磁绕组之间的互感 $$M\cos(p\phi)$$ 随转子位置脉振；凸极机中气隙磁导按两倍电角度变化，自感具有 $$L_{aa} = L_0 + L_2\cos 2\theta$$ 形式。
5. 位置相关电感是转矩之源：转矩等于共能对机械角的偏导。互感项给出同步转矩 $$T = -pM i_f i_a\sin(p\theta)$$，自感双倍角项给出磁阻转矩 $$T = -pL_2 i_a^2\sin 2\theta$$。dq0 变换把位置相关的电感矩阵化为常数，是后续动态分析的基础。

1. 由方波磁动势的傅里叶展开，推导整距集中绕组的磁动势表达式 (1)，说明为什么只存在奇数阶空间谐波，以及基波幅值为什么是 $$(4/\pi)(NI/2p)$$。
2. 用三角恒等式把三相平衡电流产生的磁场分解为前向与后向行波，验证 $$n = 1, 7, \ldots$$ 阶谐波前向、$$n = 5, 11, \ldots$$ 阶谐波后向、三的倍数阶谐波为零，并解释旋转磁场转速为什么是 $$\omega/p$$。
3. 由磁链公式 (12) 与绕组因数定义 (14)，完整推导同步电感 (16) 与零序电感 (17)，说明 $$3/2$$ 与 3 两个因子的物理来源。
4. 一个三相、四极（$$p = 2$$）定子，每极每相三个槽，槽距角 $$20°$$ 电角度，整距绕组。求基波分布因数 $$k_{b1}$$，并与每极每相两槽的绕组比较，说明增加每极每相槽数对谐波的抑制效果。
5. 圆转子电机的励磁绕组与电枢互感幅值 $$M = 0.5$$ H，励磁电流 $$I_f = 8$$ A，电枢电流幅值 $$I_a = 12$$ A，$$p = 2$$。求同步转矩平均值的峰值，并写出瞬时转矩随功角的变化关系。
6. 一台磁阻电机直轴与交轴电感 $$L_d = 0.08$$ H、$$L_q = 0.03$$ H，相电流幅值 $$I = 15$$ A。求磁阻转矩平均值的峰值；若把转子改为圆转子使 $$L_q = L_d$$，磁阻转矩如何变化，并解释原因。
