## 一、本章概要 (Overview)

**核心问题与动机**

电机是依赖铁心中磁通运行的电磁装置。直接对三维磁场求解麦克斯韦方程组在工程分析中过于复杂。磁路 (magnetic circuit) 方法提供了一种集总参数 (lumped parameter) 化思路：把磁场系统分解为离散元件——磁阻 (reluctance)、磁动势源与磁通——再借助网络约束（类似基尔霍夫定律）和元件本构关系（类似欧姆定律）求解。这一方法把矢量场问题降维为标量的电路方程，是电机分析的基础工具。其成立的前提是磁通约束：高磁导率铁心使磁通集中于确定的路径，只有气隙等低磁导率环节承载实质磁通，磁场因此可以被离散为若干"磁通管"。

**与前后章节的逻辑关系**

- 第0章引入了电磁力与能量法的基本框架；磁通密度 $$B$$ 是产生电磁力的媒介。
- 本章建立磁路模型，后续章节中电机的等效电路（激磁电抗、磁化电流、磁场定向控制所需的磁链估计）都建立在这一模型之上。
- 磁路模型的局限性（漏磁、磁饱和、磁滞、涡流）分别在后续章节展开；本章先建立理想化模型，再讨论需要修正之处。

## 二、物理机制与数学推导 (Physics & Math Derivation)

### 2.1 磁通与磁通连续性

磁通 (magnetic flux) 定义为磁通密度 $$B$$ 对曲面的通量。对磁路元件 $$k$$，取其截面上的一束磁力线，定义磁通为

$$\Phi_k = \iint_{S_k} \vec{B}\cdot\vec{n}\,da$$

高斯定律 (Gauss's law) 指出磁通密度场是无散场：从空间中任意闭曲面流出的净磁通恒为零

$$\oint_S \vec{B}\cdot\vec{n}\,da = 0$$

若把某一节点周围的所有磁通管全部计入求和，则它们之和必为零：

$$\sum_k \Phi_k = 0$$

这构成磁路中的节点约束，与电路中基尔霍夫电流定律 (KCL) 的地位相同。物理含义是磁通连续：进入节点的磁通等于离开节点的磁通，不存在磁通在节点处凭空产生或消失。

### 2.2 磁动势与安培定律

安培定律 (Ampere's law) 的积分形式为

$$\oint \vec{H}\cdot d\vec{l} = \iint_S \vec{J}\cdot\vec{n}\,da$$

式中左侧闭合回路是右侧开口曲面的边界，右侧是被回路包围的总传导电流。若回路包围 $$N$$ 匝载流 $$I$$ 的绕组，则

$$\oint \vec{H}\cdot d\vec{l} = NI$$

仿照电路中的电动势 (emf, 电压) 定义，定义磁动势 (magnetomotive force, mmf) 为磁场强度沿路径的线积分：

$$F_k = \int_{a_k}^{b_k} \vec{H}\cdot d\vec{l}$$

同时定义回路包围的电流为

$$F_0 = \iint_S \vec{J}\cdot\vec{n}\,da$$

于是安培定律给出回路约束：

$$\sum_k F_k = F_0$$

这与基尔霍夫电压定律 (KVL) 在形式上对应，差别在于磁路回路的右侧存在源项 $$F_0$$，而电路的 KVL 右侧为零，因此磁路类比并非严格同构：源项 $$F_0$$ 是磁动势的"发生器"，对应穿过回路所包围曲面的绕组电流。正负号由右手定则确定：右手手指沿闭合回路方向环绕时，拇指指向曲面的正法向，若绕组电流沿正法向穿过曲面则 $$F_0$$ 取正。工程计算中，围绕同一磁路沿任一闭合路径求和得到的磁动势降相等，这与电路分析中沿不同路径计算电压差得到同一结果是同一思想。

### 2.3 磁阻与磁路欧姆定律

考虑一段截面积为 $$A$$、长度为 $$l$$、磁导率 (permeability) 为 $$\mu$$ 的均匀磁路元件，其内磁通为 $$\Phi$$。若忽略边缘场，则有

$$\Phi = BA, \qquad H = \frac{B}{\mu}$$

磁动势为磁场强度与路径长度的乘积：

$$F = Hl = \frac{B}{\mu} l = \Phi \frac{l}{\mu A}$$

定义磁阻 (reluctance) 为磁动势与磁通的比值：

$$\mathcal{R} = \frac{F}{\Phi} = \frac{l}{\mu A}$$

其倒数称为磁导 (permeance)，记为 $$P = 1/\mathcal{R}$$，对应电路中的电导。于是得到磁路欧姆定律：

$$F = \Phi\mathcal{R}$$

把磁路欧姆定律与安培定律结合，可得到完整推导。对由 $$k$$ 段元件串联而成的闭合磁路，磁通在各段中连续且相同：

$$\begin{aligned}
\oint \vec{H}\cdot d\vec{l} &= \sum_k H_k l_k = NI \\
\sum_k \frac{B_k}{\mu_k} l_k &= NI \\
\Phi \sum_k \frac{l_k}{\mu_k A_k} &= NI
\end{aligned}$$

定义等效磁阻 $$\mathcal{R}_\text{eq} = \sum_k \mathcal{R}_k$$，即串联磁阻相加，得到

$$\Phi = \frac{NI}{\sum_k \mathcal{R}_k}$$

与电阻的串并联规律一致，磁阻串联时相加，并联时按倒数相加。串联磁路中磁通相同、磁动势降相加，对应两段磁路依次承接同一束磁通；并联磁路中磁动势相同、磁通相加，对应同一磁动势同时驱动多条磁通路径。电机磁路最常见的形态是铁心与气隙串联，故磁通由铁心段与气隙段的磁阻之和共同决定。

### 2.4 磁路与电路的完整类比

磁路与电路的对偶关系可汇总如下。

| 类别 | 电路量 (Electric) | 磁路量 (Magnetic) |
|------|--------------------|--------------------|
| 广义驱动量 | 电压 $$V$$（电动势） | 磁动势 $$F = NI$$（mmf） |
| 广义流量 | 电流 $$I$$ | 磁通 $$\Phi$$ |
| 广义阻力 | 电阻 $$R = \frac{l}{\sigma A}$$ | 磁阻 $$\mathcal{R} = \frac{l}{\mu A}$$ |
| 广义导电性 | 电导 $$G = 1/R$$ | 磁导 $$P = 1/\mathcal{R}$$ |
| 节点约束 | 基尔霍夫电流定律 $$\sum I_k = 0$$ | 磁通连续性 $$\sum \Phi_k = 0$$ |
| 回路约束 | 基尔霍夫电压定律 $$\sum V_k = 0$$ | 安培回路定律 $$\sum F_k = F_0$$ |
| 本构关系 | 欧姆定律 $$V = IR$$ | 磁路欧姆定律 $$F = \Phi\mathcal{R}$$ |
| 传导介质 | 高电导率材料（导线） | 高磁导率材料（铁心） |

高磁导率铁心在磁路中的角色对应电路中的导线：铁心内的磁动势降可忽略，磁动势几乎全部落在气隙等低磁导率元件上。以单气隙铁心（Class Notes 2 图4、图5）为例，等效磁路是一个磁动势源串联一个气隙磁阻：

```text
   ┌─────── F = N I (磁动势源) ───────┐
   │                                   │
   │               Φ                   │
   └────────── R_gap (气隙磁阻) ────────┘
```

对应的电学类比为电压源串联电阻：

```text
   ┌─────────── V (电压源) ────────────┐
   │                                   │
   │                I                  │
   └─────────── R (电阻) ──────────────┘
```

由磁路欧姆定律直接得到气隙磁通

$$\Phi = \frac{NI}{\mathcal{R}_g} = \frac{\mu_0 A}{g} NI$$

### 2.5 磁链与电感

电机分析中，电感由磁链 (flux linkage) 定义。磁链为每匝磁通与匝数的乘积：

$$\lambda = N\Phi$$

把磁路欧姆定律代入：

$$\lambda = N \cdot \frac{NI}{\sum_k \mathcal{R}_k} = \frac{N^2}{\sum_k \mathcal{R}_k} I$$

与线性电感定义 $$\lambda = L i$$ 比较，得到

$$L = \frac{N^2}{\sum_k \mathcal{R}_k} = \frac{N^2}{\mathcal{R}_\text{eq}}$$

电感与磁阻成反比。增大匝数、减小气隙（降低磁阻）都能提高电感；反之，饱和使磁阻增大，电感随之下降。对气隙占主导的铁心磁路，电感近似为

$$L \approx \frac{N^2 \mu_0 A}{g}$$

## 三、模型与方法精解 (Models & Methods)

### 3.1 气隙在磁路中的作用

铁心磁导率远大于空气磁导率：$$\mu_\text{iron} = \mu_r \mu_0$$，其中相对磁导率 (relative permeability) $$\mu_r$$ 对电工钢为数千量级。因此气隙虽然短，其磁阻却可能超过铁心。气隙磁阻与铁心磁阻之比为

$$\frac{\mathcal{R}_g}{\mathcal{R}_\text{iron}} = \frac{g/(\mu_0 A_g)}{l_\text{iron}/(\mu_r \mu_0 A_\text{iron})} = \frac{g}{l_\text{iron}} \mu_r \frac{A_\text{iron}}{A_g}$$

气隙磁阻的主导地位来自两点：一是 $$g \ll l_\text{iron}$$，二是 $$\mu_r$$ 很大，两者部分抵消后仍通常使气隙磁阻占优。气隙是电机磁路中磁动势降的主要集中点，也是气隙磁能储存与电磁力产生的位置，因此电机设计高度关注气隙尺寸与气隙磁通密度。

### 3.2 边缘效应 (Fringing)

前述推导假设磁通严格垂直穿过面积为 $$A$$ 的气隙。实际磁力线在铁心端面边缘向外扩展，使有效气隙截面积大于几何面积，这一现象称为边缘效应 (fringing)。对矩形极面（宽度 $$w$$、深度 $$D$$、气隙 $$g$$），一阶修正取有效面积为

$$A_\text{eff} = (w + g)(D + g)$$

边缘效应降低气隙磁阻，使磁通略大于按几何面积计算的估计值。Class Notes 2 指出这一忽略"在实践中往往需要修正"。气隙较大或极面较小时，修正量不可忽略；精确计算可用经验公式或数值方法（如有限元）。

### 3.3 漏磁 (Leakage Flux)

磁通不一定全部沿设计磁路穿过目标气隙。部分磁力线绕过目标路径，例如从铁心一腿经绕组窗口的空气直接回到另一腿，这部分称为漏磁 (leakage flux)。漏磁路径经过大量空气，磁阻很高，故通常只占主磁通的一小部分。漏磁不参与力矩产生，但构成漏电感，影响绕组暂态行为与换向特性。磁路集总模型以高磁导率铁心"约束"磁通为前提；Class Notes 2 通过磁通约束分析说明：铁心边界处与表面平行的磁场分量极小，因此从铁心表面发出的磁力线近似垂直表面，且离开铁心进入空气的磁力线路径很长、磁动势相同而磁通很弱，故磁通主要由低磁阻气隙承载。

### 3.4 磁饱和与 B-H 曲线

铁磁材料的磁通密度与磁场强度关系由 B-H 曲线 (B-H curve) 描述。低场区线性近似成立：$$B = \mu H$$，$$\mu$$ 较大且近似恒定。随 $$H$$ 增大，磁化达到极限，铁心的磁通密度在 1.5 T 至 2 T 量级趋于平缓，磁导率下降，这一现象称为磁饱和 (magnetic saturation)。

饱和使磁阻不再恒定，而是随磁通变化：$$\mathcal{R}(\Phi) = l/(\mu(B) A)$$，$$\mu(B)$$ 随 $$B$$ 减小。磁路模型因此变为非线性，叠加原理不再适用。B-H 曲线从线性段过渡到饱和段的弯曲区域称为膝部 (knee)：设计工作点应位于膝部以下，此时磁导率仍接近其峰值，磁动势需求与磁通近似成正比；一旦进入膝部以上，再增大磁动势只能换来越来越小的磁通增量，磁路效率明显下降。工程后果有三：其一，磁路的工作点应设计在 B-H 曲线膝部以下，避免过度饱和；其二，饱和限制铁心可承载的最大磁通密度，制约电机转矩密度；其三，饱和使电感随电流下降，影响大电流工况下的电机行为。

### 3.5 旋转电机中的气隙

旋转电机不存在无气隙的闭合铁心磁路。原因在于转子必须相对定子自由旋转，二者之间必须有机械气隙；同时，气隙磁通与转子电流的相互作用正是转矩产生的机制，气隙是能量转换的场所。由于气隙磁阻占主导，电机设计的核心任务之一是在满足机械间隙要求的前提下尽量缩短气隙，以降低磁动势需求（磁化电流）、提高功率因数与转矩密度。

### 3.6 磁性材料：软磁与硬磁、磁滞

磁导率衡量材料对磁通的传导能力，相对磁导率 $$\mu_r = \mu/\mu_0$$ 以其空磁导率为基准。按磁滞特性，磁性材料分为两类。

- 软磁材料 (soft magnetic materials)：磁导率高、矫顽力低，B-H 回线窄，磁化与去磁容易，用于铁心与叠片（电工钢）。
- 硬磁材料 (hard magnetic materials)：矫顽力高，B-H 回线宽，磁化后保留较强剩磁，用于永磁体。

磁滞 (hysteresis) 指铁磁材料的 $$B$$ 变化滞后于 $$H$$：反复磁化一周的损耗正比于 B-H 回线包围的面积，单位体积每周损耗为

$$w_h = \oint H\,dB$$

磁滞损耗是铁心损耗的组成部分之一，其机理与涡流损耗将在后续关于损耗机制的章节（涡流、表面阻抗与损耗机制）中展开。磁滞还导致磁化过程不可逆，是磁路模型精度的另一项限制：严格说，$$B$$ 与 $$H$$ 之间不存在单值函数关系，同一磁场强度对应多条可能的磁通密度取值。工程处理是在给定工作点附近用一条近似的单值磁化曲线代替回线，磁路欧姆定律与电感公式在每一工作点附近依然适用。

## 四、推导与算例 (Derivations & Examples)

以下算例沿用 Class Notes 2 的 C 形铁心结构，并补充具体数值以演示计算流程。铁心几何参数：气隙 $$g = 1\times 10^{-3}$$ m，极面宽度 $$w = 20$$ mm，深度 $$D = 30$$ mm，故 $$A = wD = 6\times 10^{-4}$$ m²。真空气隙磁导率 $$\mu_0 = 4\pi\times 10^{-7} \approx 1.257\times 10^{-6}$$ H/m。

### 4.1 算例一：等气隙 C 形铁心（已知安匝求磁通）

铁心由两个 C 形铁件拼成，两个气隙面积相同。每个气隙的磁阻为

$$\mathcal{R}_g = \frac{g}{\mu_0 A} = \frac{1\times 10^{-3}}{1.257\times 10^{-6} \times 6\times 10^{-4}} \approx 1.33\times 10^{6}\ \text{H}^{-1}$$

两个气隙串联，等效磁阻

$$\mathcal{R}_\text{eq} = 2\mathcal{R}_g \approx 2.65\times 10^{6}\ \text{H}^{-1}$$

绕组 $$N = 100$$ 匝，电流 $$I = 2$$ A，磁动势 $$F_0 = NI = 200$$ A·匝。磁路欧姆定律给出磁通

$$\Phi = \frac{NI}{\mathcal{R}_\text{eq}} = \frac{200}{2.65\times 10^{6}} \approx 7.54\times 10^{-5}\ \text{Wb}$$

气隙磁通密度

$$B = \frac{\Phi}{A} = \frac{7.54\times 10^{-5}}{6\times 10^{-4}} \approx 0.126\ \text{T}$$

与笔记公式 $$B = \mu_0 N I/(2g)$$ 直接计算一致。

### 4.2 算例二：两侧气隙面积不同的铁心

设右侧气隙面积为左侧的两倍，两气隙长度相同 $$g$$。两个磁阻分别为

$$\mathcal{R}_1 = \frac{g}{\mu_0 A}, \qquad \mathcal{R}_2 = \frac{g}{2\mu_0 A}$$

两气隙串联，等效磁阻为

$$\mathcal{R}_\text{eq} = \mathcal{R}_1 + \mathcal{R}_2 = \frac{3}{2}\frac{g}{\mu_0 A}$$

磁通为

$$\Phi = \frac{NI}{\mathcal{R}_\text{eq}} = \frac{2}{3}\frac{\mu_0 A NI}{g}$$

代入算例一数值：$$\Phi \approx 1.01\times 10^{-4}$$ Wb。左侧气隙磁通密度

$$B_1 = \frac{\Phi}{A} = \frac{2}{3}\frac{\mu_0 NI}{g} \approx 0.168\ \text{T}$$

右侧气隙磁通密度

$$B_2 = \frac{\Phi}{2A} = \frac{1}{3}\frac{\mu_0 NI}{g} \approx 0.084\ \text{T}$$

串联磁路中磁通处处相同，气隙面积大的一侧磁通密度低。这对应磁路中"面积增大、磁阻下降"的规律。

### 4.3 算例三：给定磁通求所需安匝数

设计要求等气隙铁心在气隙中达到磁通密度 $$B = 1.0$$ T。所需磁通为

$$\Phi = BA = 1.0 \times 6\times 10^{-4} = 6\times 10^{-4}\ \text{Wb}$$

由磁路欧姆定律，所需磁动势为

$$NI = \Phi \mathcal{R}_\text{eq} = 6\times 10^{-4} \times 2.65\times 10^{6} \approx 1590\ \text{A}\cdot\text{匝}$$

若电流保持 $$I = 2$$ A，则需匝数 $$N = 795$$；若匝数保持 $$N = 100$$，则需电流 $$I = 15.9$$ A。

现在计入铁心磁阻。设铁心路径总长 $$l_\text{iron} = 0.3$$ m，相对磁导率 $$\mu_r = 2000$$，则

$$\mathcal{R}_\text{iron} = \frac{l_\text{iron}}{\mu_r \mu_0 A} = \frac{0.3}{2000 \times 1.257\times 10^{-6} \times 6\times 10^{-4}} \approx 1.99\times 10^{5}\ \text{H}^{-1}$$

总磁阻 $$\mathcal{R}_\text{eq} = 2.85\times 10^{6}\ \text{H}^{-1}$$，所需磁动势 $$NI = 1710$$ A·匝，比忽略铁心时增大约 7.5%。本例验证了 3.1 节的结论：气隙仅 1 mm 却贡献了等效磁阻的绝大部分。若工作点 $$B = 1.0$$ T 已使铁心进入饱和区，$$\mu_r$$ 进一步下降，铁心磁阻占比还会上升，这也是设计需留饱和裕量的原因之一。

## 五、核心 Takeaway (Takeaways)

1. 磁路把磁场问题降维为电路问题：磁动势 $$F = NI$$ 驱动磁通 $$\Phi$$ 流过磁阻 $$\mathcal{R} = l/(\mu A)$$，服从磁路欧姆定律 $$NI = \Phi\mathcal{R}$$，其推导源自安培定律与磁通连续性。
2. 磁路与电路一一对应：mmf 对应 emf，磁通对应电流，磁阻对应电阻，安培回路定律对应 KVL，磁通连续性对应 KCL；高磁导率铁心对应高电导率导线。
3. 气隙磁阻在电机磁路中占主导，因为 $$\mu_\text{iron} \gg \mu_0$$；边缘效应增大有效气隙面积，漏磁路径则绕开目标气隙，二者都是磁路模型需要修正的来源。
4. 磁饱和使磁阻变为磁通的函数，磁路模型非线性化，叠加原理失效；设计需把工作点保持在 B-H 曲线膝部以下，并理解饱和对电感与转矩密度的影响。
5. 电感由磁链导出：$$L = N^2/\mathcal{R}_\text{eq}$$，与磁阻成反比；饱和与气隙尺寸都通过磁阻直接影响电感。

## 六、练习与思考 (Exercises)

1. 证明磁路中两个磁阻并联时的等效磁阻公式，并说明它对应的磁通约束与磁动势约束。
2. 等气隙 C 形铁心，气隙 $$g = 0.5$$ mm，面积 $$A = 8\times 10^{-4}$$ m²，绕组 $$N = 200$$ 匝。求电流 $$I = 1.5$$ A 时的气隙磁通密度；若要求磁通密度 0.8 T，求所需电流。
3. 若将算例三中铁心磁导率由 $$\mu_r = 2000$$ 提高到 $$\mu_r = 10000$$，所需磁动势变化多少？说明在何种条件下铁心磁阻可以忽略。
4. 边缘效应使有效气隙面积增大。对 $$w = 20$$ mm、$$D = 30$$ mm、$$g = 1$$ mm 的极面，计算 $$A_\text{eff}/A$$，并估计忽略边缘效应对磁通估计的影响比例。
5. 磁饱和使电感随电流增大而下降。说明在磁路模型中这一效应如何体现，以及它对电机大电流启动工况可能产生的影响。
6. 磁滞损耗正比于 B-H 回线面积。结合软磁与硬磁材料特性，解释为何电机铁心选用软磁材料、永磁体选用硬磁材料。
