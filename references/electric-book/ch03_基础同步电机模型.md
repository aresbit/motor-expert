# 第3章: 基础同步电机模型 (Elementary Synchronous Machine Models)
> 原课程: MIT 6.685 — Electric Machines, Fall 2013 (James L. Kirtley Jr.)

## 一、本章概要 (Overview)

同步电机 (synchronous machine) 是电机的主要类别之一，广泛应用于大型汽轮发电机、水轮发电机与工业电动机。本章的目标是建立一个简单但物理上有意义的同步电机模型，既用于分析运行特性，也用于建立额定值 (rating) 与尺寸之间的关系。

同步电机的核心特征在于"同步"二字：稳态运行时转子以与电频率一致的机械速度旋转，即 $$p\Omega = \omega$$，其中 $$p$$ 为极对数 (pole pair)，$$\Omega$$ 为转子机械角速度，$$\omega$$ 为电角频率。与感应电机 (induction machine) 不同，同步电机只有在同步转速下才能产生稳态转矩。转子上的励磁绕组 (field winding) 通入直流电流，产生一个相对于转子固定的磁场；定子三相电枢绕组 (armature winding) 通入平衡的三相电流，产生一个在空间旋转的磁动势波。两者相互作用产生转矩，而转矩的方向与大小取决于两个磁场之间的空间夹角。

本章建立模型的逻辑链如下：

- 从电流片 (current sheet) 的物理图像出发，推导表面牵引力与转矩的表达式，给出转矩随电机尺寸的标度关系。
- 由三相平衡电流的磁动势叠加，推导恒幅旋转磁动势 (rotating mmf) 的完整数学形式。
- 把绕组近似为正弦分布的连续绕组，计算自感、互感，从而把电磁转矩转化为电感的函数。
- 建立三相集中参数模型，推导磁链方程、电压方程与内部电压（反电动势，back EMF）。
- 得到稳态等效电路、同步电抗 (synchronous reactance) $$X_d$$、功率角 (power angle / torque angle) $$\delta$$ 以及功率—转矩—功角关系。
- 处理励磁电流对无功功率与功率因数的控制（V 型曲线与容量图）。
- 推广到凸极 (salient pole) 电机，引入两轴 (two-axis) 模型与磁阻转矩 (reluctance torque)。

与前后章节的关系：第 1 章建立了磁路基础，第 2 章处理涡流与损耗。本章把电机抽象为集中参数等效电路，是后续绕组电感、dq0 变换与暂态分析的基础。

## 二、物理机制与数学推导 (Physics & Math Derivation)

### 2.1 电流片物理图像

考虑一个理想化的简单电机（课程笔记图 1）：同轴的圆柱转子与圆柱定子，两者由高磁导率材料构成（暂近似为无穷大磁导率 $$\mu \to \infty$$），转子的外表面与定子的内表面载有沿轴向（$$z$$ 向）且随角度正弦分布的电流片：

$$K_{zS} = K_S \cos p\theta, \qquad K_{zR} = K_R \cos p(\theta - \varphi)$$

其中 $$\varphi$$ 为转子的物理角度，转子上的电流分布随转子固定。假设气隙 (air gap) 尺寸 $$g$$ 远小于半径 $$R$$，即 $$g \ll R$$，则气隙中的径向磁通密度 $$B_r$$ 几乎不随半径变化，并满足：

$$\frac{\partial B_r}{\partial (R\theta)} = -\mu_0 \frac{K_{zS} + K_{zR}}{g}$$

对 $$\theta$$ 积分，得到径向磁通密度：

$$B_r = -\frac{\mu_0 R}{p g} \left( K_S \sin p\theta + K_R \sin p(\theta - \varphi) \right)$$

表面电流分布同时就是切向磁场：在定子表面 $$H_\theta = -K_{zS}$$，在转子表面 $$H_\theta = K_{zR}$$。于是转子表面的牵引力 (traction) 为磁通密度与表面电流之积：

$$\tau_\theta = T_{r\theta} = -\frac{\mu_0 R}{p g} \left( K_S \sin p\theta + K_R \sin p(\theta - \varphi) \right) K_R \cos p(\theta - \varphi)$$

对空间角度求平均，只有同频项贡献非零平均：

$$\langle \tau_\theta \rangle = -\frac{\mu_0 R}{2 p g} K_S K_R \sin p\varphi$$

在定子表面做同样的计算得到相同结果（符号相反）。转矩为表面积乘以平均牵引力：

$$T = 2\pi R^2 \ell \langle \tau_\theta \rangle = \frac{\mu_0 \pi R^3 \ell}{p g} K_S K_R \sin p\varphi$$

其中 $$\ell$$ 为电机的轴向长度。这一表达式给出了同步电机转矩的第一性原理来源：转矩正比于定、转子表面电流密度的乘积与转子空间角的正弦。

几点观察值得记录。第一，给定表面电流密度 $$K_S, K_R$$ 时，转矩随线性尺寸的三次方增长，即切应力不随电机尺寸变化，转矩密度与体积之比近似恒定。第二，若保持气隙 $$g$$ 不变，转矩随体积的四次方增长，而体积本身随三次方增长，故转矩能力随体积的 $$4/3$$ 次方增长。第三，这一估计还偏保守：实际表面电流密度是体电流密度与绕组深度的乘积，随着半径增大，定、转子表面电流密度都会增长，因此转矩与功率密度随体积的增长会比线性略快。第四，电流分布有相互对齐的倾向：实际运行中定子电流分布不是静态的，而是在空间旋转：

$$K_{zS} = K_S \cos(p\theta - \omega t)$$

这个旋转的电流片拖着转子同步旋转。第五，对给定的电流对存在最大可维持转矩；只要实际负载转矩小于该值，转子就会自行调整到正确的功角。

### 2.2 三相平衡电流产生旋转磁动势

上文的电流片图像说明定子需要一个旋转的电流分布。三相绕组正是实现这一目标的方式：三套相同的绕组在空间上相隔 $$120^\circ$$（电角度 $$2\pi/3$$），通入时间相位互差 $$120^\circ$$ 的平衡电流。先看每一相单独产生的磁动势。

设每相电流的幅值为 $$I$$，磁动势的空间分布为正弦，第 $$a$$ 相绕组轴线位于空间角 $$\theta = 0$$ 处。令空间电角度为 $$p\theta$$，则各相产生的脉动磁动势为：

$$F_a = F \cos p\theta \cos \omega t$$

$$F_b = F \cos\left(p\theta - \frac{2\pi}{3}\right) \cos\left(\omega t - \frac{2\pi}{3}\right)$$

$$F_c = F \cos\left(p\theta + \frac{2\pi}{3}\right) \cos\left(\omega t + \frac{2\pi}{3}\right)$$

其中 $$F$$ 为每相磁动势的幅值。每一相的磁动势都是固定于空间、随时间脉动的波。三者的叠加：

$$\begin{aligned} F(\theta, t) &= F_a + F_b + F_c \\ &= F \left[ \cos p\theta \cos \omega t + \cos\left(p\theta - \tfrac{2\pi}{3}\right)\cos\left(\omega t - \tfrac{2\pi}{3}\right) + \cos\left(p\theta + \tfrac{2\pi}{3}\right)\cos\left(\omega t + \tfrac{2\pi}{3}\right) \right] \end{aligned}$$

利用积化和差公式 $$\cos A \cos B = \frac{1}{2}\left[\cos(A+B) + \cos(A-B)\right]$$ 逐项展开。以 $$a$$ 相为例：

$$\cos p\theta \cos \omega t = \frac{1}{2}\left[ \cos(p\theta + \omega t) + \cos(p\theta - \omega t) \right]$$

$$b$$ 相：

$$\cos\left(p\theta - \tfrac{2\pi}{3}\right)\cos\left(\omega t - \tfrac{2\pi}{3}\right) = \frac{1}{2}\left[ \cos(p\theta + \omega t - \tfrac{4\pi}{3}) + \cos(p\theta - \omega t) \right]$$

$$c$$ 相：

$$\cos\left(p\theta + \tfrac{2\pi}{3}\right)\cos\left(\omega t + \tfrac{2\pi}{3}\right) = \frac{1}{2}\left[ \cos(p\theta + \omega t + \tfrac{4\pi}{3}) + \cos(p\theta - \omega t) \right]$$

把所有含 $$\cos(p\theta - \omega t)$$ 的项合并，共得三项，即 $$\frac{3}{2}F\cos(p\theta - \omega t)$$。而含 $$\cos(p\theta + \omega t)$$ 的三个项，其相位分别为 $$0$$、$$-4\pi/3$$、$$+4\pi/3$$，恰好构成间隔 $$120^\circ$$ 的三个相量，其和为 $$0$$。于是：

$$F(\theta, t) = \frac{3}{2} F \cos(p\theta - \omega t)$$

这就是旋转磁动势的完整推导。三个脉动磁场的叠加是一个幅值恒为 $$\frac{3}{2}F$$、以角速度 $$\omega/p$$ 沿空间旋转的波。幅值不随时间变化，这一特性正是三相平衡系统区别于单相系统的根本原因：单相磁动势是脉动的，而三相合成磁动势是恒幅旋转的。

### 2.3 连续绕组近似与电感

实际绕组无法实现纯正弦的电流分布，但可以用匝数分布来近似。定义定、转子沿表面的匝数密度 (turns density)：

$$n_S = \frac{N_S}{2R} \cos p\theta, \qquad n_R = \frac{N_R}{2R} \cos p(\theta - \varphi)$$

其中 $$N_S, N_R$$ 分别为定、转子绕组的总匝数。检验：$$\int_{-\pi/2}^{\pi/2} p n_S R d\theta = N_S$$。匝数密度为正表示导体电流沿 $$+z$$ 向，为负表示沿 $$-z$$ 向。这样的绕组由若干基本线圈构成，正负两半相隔电角度 $$\pi/p$$。

在这样的近似下，表面电流密度为：

$$K_S = \frac{N_S I_S}{2R}, \qquad K_R = \frac{N_R I_R}{2R}$$

与电流片图像一致。现在可以计算电感。若仅定子励磁，气隙径向磁场强度为：

$$H_r = -\frac{N_S I_S}{2 g p} \sin p\theta$$

基本线圈（跨越角 $$\pi/p$$）交链的磁通为：

$$\Phi_i(\theta) = \int_{\theta - \pi/p}^{\theta} \mu_0 H_r(\theta') \ell R d\theta' = \frac{\mu_0 N_S I_S \ell R}{p^2 g} \cos p\theta$$

整条绕组的磁链是全体基本线圈磁链沿匝数分布的积分：

$$\lambda_S = p \int_{-\pi/(2p)}^{\pi/(2p)} \Phi_i(\theta) n_S(\theta) R d\theta = \mu_0 \frac{\pi \ell R N_S^2}{4 g p^2} I_S$$

由此得到定子自感 (self inductance)：

$$L_S = \mu_0 \frac{\pi \ell R N_S^2}{4 g p^2}$$

同样的过程（换用相应的空间变量）得到转子自感：

$$L_R = \mu_0 \frac{\pi \ell R N_R^2}{4 g p^2}$$

励磁一方、计算另一方交链的磁链即得互感 (mutual inductance)：

$$M(\varphi) = \mu_0 \frac{\pi \ell R N_S N_R}{4 g p^2} \cos p\varphi$$

互感随转子角度按余弦变化：当两绕组轴线对齐时互感最大，垂直时为零。由磁场共能 (coenergy) 求转矩：

$$W_m' = \frac{1}{2} L_S I_S^2 + \frac{1}{2} L_R I_R^2 + M(\varphi) I_S I_R$$

$$T = \frac{\partial W_m'}{\partial \varphi} = -\mu_0 \frac{\pi \ell R N_S N_R}{4 g p} I_S I_R \sin p\varphi$$

代入 $$N_S I_S = 2R K_S$$、$$N_R I_R = 2R K_R$$，得到与电流片方法完全一致的结果。这说明磁场观点与电路（电感）观点是同一物理过程的两种等价表述。

### 2.4 三相集中参数模型的磁链与电压方程

现在考察最简的多相同步电机模型：转子与前文相同，定子改为三套相同的绕组，空间上彼此相隔电角度 $$120^\circ = 2\pi/3$$。三相绕组的自感相同，记为 $$L_a$$。由于任意两相之间的空间夹角相同，相间互感也相同，并且由几何关系可知它等于自感的一半取负号：

$$L_{ab} = L_{ac} = L_{bc} = -\frac{1}{2} L_a$$

转子励磁绕组与各定子相之间的互感为（记幅值 $$M = \mu_0 \pi \ell R N_a N_f / (4 g p^2)$$）：

$$M_{af} = M \cos p\varphi, \qquad M_{bf} = M \cos\left(p\varphi - \frac{2\pi}{3}\right), \qquad M_{cf} = M \cos\left(p\varphi + \frac{2\pi}{3}\right)$$

于是转矩可写为（课程笔记第 1 章给出）：

$$T = -pM i_f \left[ i_a \sin p\varphi + i_b \sin\left(p\varphi - \frac{2\pi}{3}\right) + i_c \sin\left(p\varphi + \frac{2\pi}{3}\right) \right]$$

考察平衡运行 (balanced operation)：转子以恒定速度旋转、励磁电流恒定，三相定子电流为时间上的正弦量，幅值相同、相位互差 $$120^\circ$$：

$$p\varphi = \omega t + \delta_i, \qquad i_f = I_f$$

$$i_a = I \cos \omega t, \qquad i_b = I \cos\left(\omega t - \frac{2\pi}{3}\right), \qquad i_c = I \cos\left(\omega t + \frac{2\pi}{3}\right)$$

代入转矩表达式，经过直接的三角运算，得到恒定转矩：

$$T = -\frac{3}{2} pM I I_f \sin \delta_i$$

其中 $$\delta_i$$ 称为电流角（转矩角之一）。电机以这种方式运行时转矩为常数，不随时间脉动。值得注意的是，这里存在多个"转矩角"：电流与转子磁场之间的夹角、以及后文的电压与内电势之间的夹角，需要区分。

从电气端口观察。$$a$$ 相绕组的磁链为：

$$\lambda_a = L_a i_a + L_{ab} i_b + L_{ac} i_c + M I_f \cos p\varphi$$

平衡条件下三相电流之和为零，且各相间互感相等，于是：

$$\lambda_a = (L_a - L_{ab}) i_a + M I_f \cos p\varphi = L_d i_a + M I_f \cos p\varphi$$

其中定义了同步电感 (synchronous inductance) $$L_d = L_a - L_{ab} = \frac{3}{2} L_a$$。当电机以与电频率一致的转速运行时（同步运行），可以采用正弦稳态的复数记号：

$$i_a = I \cos(\omega t + \theta_i) = \operatorname{Re}\left\{ \tilde{I} e^{j\omega t} \right\}, \qquad \tilde{I} = I e^{j\theta_i}$$

$$\lambda_a = \operatorname{Re}\left\{ \tilde{\Lambda}_a e^{j\omega t} \right\}$$

励磁产生的磁链用 $$\tilde{I}_f = I_f e^{j\theta_m}$$ 表示。端电压为磁链的时间导数：

$$v_a = \frac{d\lambda_a}{dt} = \operatorname{Re}\left\{ j\omega \tilde{\Lambda}_a e^{j\omega t} \right\}$$

把磁链中的励磁项与电枢反应项分开，可定义内部电压 (internal voltage)：

$$E_{af} = j\omega M I_f e^{j\theta_m}$$

$$E_{af}$$ 就是同步电机的反电动势 (back EMF)：励磁磁场以同步速度扫过电枢绕组时感应出的开路电压。它滞后或超前端电压的角度由功角决定。

## 三、模型与方法精解 (Models & Methods)

### 3.1 稳态等效电路与相量方程

由电压方程与内部电压的定义，可以得到同步电机的稳态等效电路：一个内电势源 $$E_{af}$$ 串联同步电抗 $$jX_d$$，接在端电压 $$V$$ 上，其中：

$$X_d = \omega L_d$$

称为同步电抗 (synchronous reactance)。以发电机惯例（电流 $$I_g$$ 从机端流出）写出相量方程：

$$\tilde{V} = E_{af} - jX_d \tilde{I}_g$$

若改用电动机惯例（电流 $$\tilde{I}$$ 流入机端，$$\tilde{I} = -\tilde{I}_g$$），则：

$$\tilde{V} = E_{af} + jX_d \tilde{I}$$

以端电压 $$\tilde{V} = V e^{j0}$$ 为相位基准、内电势 $$E_{af} e^{j\delta}$$ 的幅角为 $$\delta$$，电动机惯例下的端电流为：

$$\tilde{I} = \frac{V - E_{af} e^{j\delta}}{jX_d}$$

课程笔记图 2 给出该等效电路的示意图：

```text
        jX_d          Ĩ
      ────┬────●───────►
          │
    +     │         +
   E_af   │         V
    -     │         -
          │
          ▼
        (内电势源)
```

其中内部电压为 $$E_{af}$$，串联电抗为 $$jX_d$$，端口为端电压 $$V$$。

### 3.2 相量图与功角

设端电压 $$V$$ 为参考（水平方向）。电动机运行时，转子磁场滞后于端电压磁链，因此内电势 $$E_{af}$$ 滞后 $$V$$ 一个角度 $$\delta$$。端电流与端电压的关系由电抗压降 $$jX_d I$$ 决定。电动机运行（过励，电流超前）的相量图（课程笔记图 3）：

```text
                 Ĩ (超前 V，过励运行)
                  ↗
                 ╱      jX_d·Ĩ (垂直于 Ĩ，超前 90°)
                ╱
    E_af ────●──────────► V (端电压，水平基准)
              ╲   δ (功角：Eaf 滞后 V)
               ╲
                ▼ E_af
```

发电机运行时电流取相反的符号，内电势 $$E_{af}$$ 超前 $$V$$ 角 $$\delta$$（课程笔记图 4）：

```text
                  E_af (超前 V 角 δ)
                    ▲
                    │ δ
                    │
    ────────────●──────► V (端电压，水平基准)
                ╲
                 ╲  jX_d·Ĩ_g (垂直于 Ĩ_g)
                  ╲
                   ▼
                  Ĩ_g (发电机电流，流出机端)
```

角度 $$\delta$$ 称为功率角或转矩角 (power angle / torque angle)，它是内电势（即转子磁场位置）与端电压（即电枢合成磁场位置）之间的夹角。转矩的符号与大小完全由 $$\delta$$ 决定。

### 3.3 功率、转矩与失步转矩

由电动机惯例，复功率为：

$$P + jQ = \frac{1}{2} V \tilde{I}^*$$

代入端电流表达式，并把电压取为峰值幅值（这是课程笔记使用的记号），展开得到单相有功与无功：

$$P_a = -\frac{1}{2} \frac{V E_{af}}{X_d} \sin \delta$$

$$Q_a = \frac{1}{2} \frac{V^2}{X_d} - \frac{1}{2} \frac{V E_{af}}{X_d} \cos \delta$$

三相总有功功率为单相的 $$3$$ 倍：

$$P = -\frac{3}{2} \frac{V E_{af}}{X_d} \sin \delta$$

功率因转矩乘以机械角速度，$$P = T \omega_m$$，而 $$\omega_m = \omega/p$$，于是转矩为：

$$T = \frac{P}{\omega_m} = -\frac{3}{2} \frac{p V E_{af}}{\omega X_d} \sin \delta$$

两个模型（电流观点与电路观点）对转矩给出相同的结果，这一点在第 3.4 节用相量几何证明。

由于 $$V, E_{af}, X_d$$ 在给定励磁与电压下均为常数，功率与转矩只随 $$\sin \delta$$ 变化。当 $$\lvert \delta \rvert = 90^\circ$$ 时功率与转矩取极值：

$$T_{\max} = \frac{3}{2} \frac{p V E_{af}}{\omega X_d}$$

$$T_{\max}$$ 称为失步转矩 (pull-out torque)。当负载转矩超过 $$T_{\max}$$ 时，转子无法维持同步，机器失去同步（失步）。

同步电机只在 $$0 < \delta < 90^\circ$$（发电机）或 $$-90^\circ < \delta < 0$$（电动机）的区间内稳定运行。原因在于稳定条件要求转矩随功角增大而增大，即 $$\partial T / \partial \delta > 0$$：

$$\frac{\partial T}{\partial \delta} = -\frac{3}{2} \frac{p V E_{af}}{\omega X_d} \cos \delta$$

当 $$\lvert \delta \rvert < 90^\circ$$ 时导数与转矩同号（自动调节方向），运行点稳定；当 $$\lvert \delta \rvert > 90^\circ$$ 时导数反号，任何微小扰动都会使功角进一步增大直至失步。因此功角的绝对范围被限制在 $$90^\circ$$ 以内。

### 3.4 两个模型的统一：相量几何

课程笔记图 5 用相量叠加说明电流观点与电压观点的等价性。端电压取为实轴，电动机运行时转子滞后角 $$\delta$$，转子磁场 $$M I_f$$ 位于相应位置，电枢电流 $$\tilde{I}$$ 与转子磁场的夹角为电流角 $$\delta_i$$。连接电枢磁链 $$L_d \tilde{I}$$ 与端磁链 $$\Lambda_t$$ 的虚线 $$OA$$ 垂直于连线，其长度为：

$$\lvert OA \rvert = L_d I \sin \delta_i = \Lambda_t \sin \delta$$

利用 $$V = \omega \Lambda_t$$、$$E_{af} = \omega M I_f$$、$$X_d = \omega L_d$$，代入整理：

$$\frac{3}{2} \frac{p V E_{af}}{\omega X_d} \sin \delta = \frac{3}{2} p M I I_f \sin \delta_i$$

两端分别是电路观点与电流观点给出的转矩。几何关系保证了两种表述严格一致。

### 3.5 标幺制

标幺制 (per-unit system) 是一种记号装置，把变量除以各自的基值，得到无量纲的标幺值。通常把基值电压与基值电流取为与电机额定值相关的量：电压基值取相电压，电流基值取线电流（均取有效值），则功率基值为：

$$P_B = 3 V_B I_B$$

阻抗基值为：

$$Z_B = \frac{V_B}{I_B}$$

需要提醒：基值取相电压、线电流并非唯一选择。也可以取线电压与三角形连接元件中的电流为基值：

$$V_{B\Delta} = \sqrt{3} V_B, \qquad I_{B\Delta} = \frac{I_B}{\sqrt{3}}$$

此时功率基值不变，而阻抗基值相差 $$3$$ 倍：$$Z_{B\Delta} = 3 Z_B$$。但由于阻抗为 $$3Z$$ 的三角形连接等价于阻抗为 $$Z$$ 的星形连接，同一系统用不同连接折算出的标幺阻抗一致。这正是标幺制的主要优点：标幺值唯一确定，而普通变量随接线方式（线电压或相电压、峰值或有效值）而变。

实际中基值通常给线电压与基功率，因此：

$$I_B = \frac{P_B}{\sqrt{3} V_{B\Delta}}, \qquad Z_B = \frac{V_{B\Delta}^2}{P_B}$$

标幺值用小写字母表示，如 $$v = V/V_B$$、$$p = P/P_B$$、$$x_d = X_d/Z_B$$。于是稳态下同步电机的有功、无功（电动机参考系，流入机端）为：

$$p = -\frac{v e_{af}}{x_d} \sin \delta, \qquad q = \frac{v^2}{x_d} - \frac{v e_{af}}{x_d} \cos \delta$$

### 3.6 无功功率与励磁控制

在正常运行中，有功功率由负载（电动机）或原动机（发电机）决定，而无功功率由有功功率与励磁电流共同决定。励磁电流 $$I_f$$ 直接控制内电势 $$E_{af}$$ 的大小，从而控制功率因数 (power factor)。

过励 (overexcited) 运行：励磁电流偏大，$$E_{af}$$ 增大，电动机吸收超前电流（向电网输送无功），发电机则向电网输送无功。欠励 (underexcited) 运行：励磁电流偏小，$$E_{af}$$ 减小，电动机吸收滞后电流，发电机吸收无功。

V 型曲线 (Vee curve)（课程笔记图 7）是电枢电流幅值与励磁电流的关系曲线，一族曲线分别对应不同的有功功率。每条曲线在单位功率因数处取最小值：此时以最小电枢电流传输给定的有功功率。曲线的右上边界为励磁电流限制，上边界为电枢电流限制，左上端由稳定性极限（$$\delta = 90^\circ$$）截断。同理可以画出把励磁电流作为有功功率函数（功率因数固定）的复励曲线 (compounding curve)。

容量图 (capability diagram)（课程笔记图 6）在无功—有功平面上描述发电机的运行能力。以 $$q = -v^2/x_d$$ 为起点，把长度为 $$v e_{af}/x_d$$ 的矢量以角度 $$\delta$$ 摆动，扫出磁场能力圆 (field limit)。第二个圆描述恒定的 $$\lvert p + jq \rvert$$，即电枢电流幅值，称为电枢能力圆 (armature limit)。第三个限制是稳定性极限 (stability limit)，对应功角不得超过 $$90^\circ$$。大容量发电机在深度欠励时定子铁心存在发热问题，往往还要附加一条端部发热限制线。

### 3.7 凸极电机的两反应理论

前文处理的是隐极 (round rotor) 机器，其定子电抗不随转子位置变化。这对大型汽轮发电机与许多两极小机器是很好的近似，但对许多同步电动机与低速发电机并不适用。后者的励磁绕组绕在钢制磁极上再固定于转子体，形成磁各向异性。相应的理论称为两反应理论 (two-reaction theory)，是后续旋转坐标变换（dq0 变换）的基础。

把电枢电流片分解为两个正交分量：一个与磁场对齐，一个与磁场正交。直轴 (direct axis) 与励磁绕组对齐，交轴 (quadrature axis) 超前直轴 $$90^\circ$$。设 $$\varphi$$ 为直轴与 $$a$$ 相轴线的夹角，则交链 $$a$$ 相的磁链为：

$$\lambda_s = \lambda_d \cos \varphi - \lambda_q \sin \varphi$$

稳态时 $$v_a = d\lambda_a/dt$$，取 $$\varphi = \omega t + \delta$$：

$$v_a = -\omega \lambda_d \sin \varphi - \omega \lambda_q \cos \varphi$$

据此可定义直、交轴电压分量：

$$V_d = -\omega \lambda_q, \qquad V_q = \omega \lambda_d$$

电压矢量超前磁链矢量 $$90^\circ$$。在线性机器中，磁链为：

$$\lambda_d = L_d I_d + M I_f, \qquad \lambda_q = L_q I_q$$

一般情况下 $$L_d \neq L_q$$：绕线励磁同步电机通常 $$L_d > L_q$$；大多数埋入式永磁电机则相反，$$L_q > L_d$$。

把端电压分解到两轴上（课程笔记图 9）：$$V_d = V \sin \delta$$、$$V_q = V \cos \delta$$，并与磁链方程联立：

$$V_d = -\omega L_q I_q = V \sin \delta$$

$$V_q = \omega L_d I_d + \omega M I_f = V \cos \delta$$

反解出直、交轴电流（这里 $$V, E_{af}, X_d, X_q$$ 均为峰值幅值）：

$$I_d = \frac{V \cos \delta - E_{af}}{X_d}, \qquad I_q = -\frac{V \sin \delta}{X_q}$$

其中 $$X_d = \omega L_d$$、$$X_q = \omega L_q$$、$$E_{af} = \omega M I_f$$。取复相量 $$V = V_d + jV_q$$、$$I = I_d + jI_q$$，复功率为：

$$P + jQ = \frac{3}{2} V I^* = \frac{3}{2} \left[ (V_d I_d + V_q I_q) + j(V_q I_d - V_d I_q) \right]$$

代入直、交轴电流并整理，得到凸极电机的功率表达式：

$$P = -\frac{3}{2} \left[ \frac{V E_{af}}{X_d} \sin \delta + \frac{V^2}{2} \left( \frac{1}{X_q} - \frac{1}{X_d} \right) \sin 2\delta \right]$$

第二项含有 $$\sin 2\delta$$，与励磁无关（不含 $$E_{af}$$），称为磁阻转矩 (reluctance torque) 分量：即使励磁为零（$$E_{af} = 0$$），由于直、交轴磁阻不同，转子仍有把自身对齐到最小磁阻位置的倾向。无功功率为：

$$Q = \frac{3}{2} \left[ \frac{V^2}{2}\left( \frac{1}{X_d} + \frac{1}{X_q} \right) - \frac{V^2}{2}\left( \frac{1}{X_q} - \frac{1}{X_d} \right) \cos 2\delta - \frac{V E_{af}}{X_d} \cos \delta \right]$$

凸极电机的相量图（课程笔记图 10）比隐极机复杂：电枢电流分解为直、交轴分量，各自产生的压降 $$jX_d I_d$$、$$jX_q I_q$$ 分别画出。一个有用的认识是内电势可写成：

$$E_{af} = E_1 + (X_d - X_q) I_d$$

其中 $$E_1$$ 位于交轴上。$$E_1$$ 正是电抗为 $$X_q$$ 的隐极机在相同电枢电流与端电压下的内电势。给定端电压 $$V$$、电流幅值 $$I$$ 与功率因数角 $$\psi$$，可求出工作点：

$$\delta = -\tan^{-1} \frac{X_q I \cos \psi}{V + X_q I \sin \psi}$$

$$E_1 = \sqrt{(V + X_q I \sin \psi)^2 + (X_q I \cos \psi)^2}$$

课程笔记图 11 对比了隐极机与凸极机的功角曲线。凸极机的峰值功率略高，且峰值位置略向 $$\delta < 90^\circ$$ 偏移。工程实践中，电力系统分析人员在暂态稳定计算中经常忽略凸极性，因为其影响相对次要。

## 四、推导与算例 (Derivations & Examples)

### 4.1 算例一：给定运行点的电流、功率与转矩

考虑一台 60 Hz、两极（$$p = 1$$）隐极同步电机，采用标幺制：$$v = 1.0$$，$$x_d = 1.0$$。励磁电流给定 $$e_{af} = 1.3$$，电动机运行，内电势滞后端电压 $$\delta = -30^\circ$$。求端电流、有功、无功与转矩。

由端电流表达式：

$$\tilde{I} = \frac{v - e_{af} e^{j\delta}}{j x_d} = \frac{1 - 1.3 e^{-j30^\circ}}{j}$$

其中 $$e^{-j30^\circ} = 0.8660 - j0.5000$$，于是：

$$\tilde{I} = \frac{1 - 1.3(0.8660 - j0.5000)}{j} = \frac{-0.1258 + j0.6500}{j} = 0.6500 + j0.1258$$

电流幅值：

$$\lvert \tilde{I} \rvert = \sqrt{0.6500^2 + 0.1258^2} = 0.662$$

电流幅角 $$\arctan(0.1258/0.6500) = 10.95^\circ$$，即电流超前电压约 $$11^\circ$$。

有功与无功：

$$p = -\frac{v e_{af}}{x_d} \sin \delta = -1.3 \times (-0.5) = 0.650$$

$$q = \frac{v^2}{x_d} - \frac{v e_{af}}{x_d} \cos \delta = 1 - 1.3 \times 0.8660 = -0.126$$

电动机吸收有功 $$0.650$$ 标幺，输出无功 $$0.126$$ 标幺（电流超前，过励运行）。校验：$$\lvert p + jq \rvert = \sqrt{0.65^2 + 0.126^2} = 0.662 = \lvert v \rvert \lvert i \rvert$$。

换成绝对单位。设额定 $$P_B = 100$$ MVA，线电压 $$13.8$$ kV，则相电压基值 $$V_B = 13.8/\sqrt{3} = 7.967$$ kV，线电流基值 $$I_B = P_B/(3V_B) = 4184$$ A。基值转矩为 $$T_B = P_B/\Omega_m = 100 \times 10^6 / (2\pi \times 60) = 2.65 \times 10^5$$ N·m。于是转矩为：

$$T = 0.650 \times 2.65 \times 10^5 = 1.72 \times 10^5 \text{ N·m}$$

### 4.2 算例二：失步转矩与稳定裕度

接上例，$$e_{af} = 1.3$$、$$x_d = 1.0$$ 时失步转矩为：

$$T_{\max} = \frac{v e_{af}}{x_d} = 1.3$$

在 $$\delta = -30^\circ$$ 下转矩为 $$0.65$$，即运行于失步转矩的 $$50\%$$，稳定裕度充足。

若降低励磁至 $$e_{af} = 0.5$$，失步转矩降为 $$0.5$$，小于所需的 $$0.65$$。此时要维持 $$0.65$$ 的有功需要 $$\sin \delta = -0.65/0.5 = -1.3$$，无实数解。这说明欠励运行不仅降低功率因数，还直接压缩稳定裕度，机器将无法承受原有的有功负荷。这正是同步电机运行中必须维持最小励磁电流的原因。

### 4.3 算例三：凸极电机的磁阻转矩分量

设凸极机标幺参数 $$x_d = 2.0$$、$$x_q = 1.2$$、$$v = 1.0$$、$$e_{af} = 1.0$$，功角 $$\delta = 30^\circ$$。凸极功率表达式（取幅值形式）：

$$p = \frac{v e_{af}}{x_d} \sin \delta + \frac{v^2}{2} \left( \frac{1}{x_q} - \frac{1}{x_d} \right) \sin 2\delta$$

代入数值：

$$p = \frac{0.5}{1} \times 0.5 + \frac{1}{2} \left( \frac{1}{1.2} - \frac{1}{2} \right) \times 0.866 = 0.25 + 0.1443 = 0.394$$

磁阻分量 $$0.1443$$ 约占总功率的 $$37\%$$。与之对比，相同参数下隐极机（无磁阻项）在 $$\delta = 30^\circ$$ 时只有 $$0.25$$，凸极机多出约 $$58\%$$。磁阻转矩在 $$\delta = 45^\circ$$ 处取峰值：

$$p_{\text{rel}, \max} = \frac{v^2}{2}\left( \frac{1}{x_q} - \frac{1}{x_d} \right) = \frac{1}{2}\left( 0.8333 - 0.5 \right) = 0.1667$$

即使励磁为零（$$e_{af} = 0$$），凸极机仍能产生高达 $$0.1667$$ 标幺的磁阻功率，这正是磁阻电机工作的原理。

### 4.4 额定值与尺寸的关系

即使使用本章的简单模型，也能建立电机额定值与尺寸的定量关系。电机额定值为：

$$\lvert P + jQ \rvert = q V I$$

其中 $$q$$ 为相数，$$V$$ 为相电压有效值，$$I$$ 为相电流有效值。先求电压。设匝数密度 $$n_a(\theta) = (N_a/2R)\cos p\theta$$，工作磁通密度为：

$$B_r(\theta) = B_0 \sin p(\theta - \varphi)$$

基本线圈交链的磁链为 $$\lambda_i(\theta) = \int_\theta^{\theta+\pi/p} \ell B_r(\theta') R d\theta'$$，整条绕组磁链为：

$$\lambda_a = p \int_{-\pi/(2p)}^{\pi/(2p)} \lambda_i(\theta) n_a(\theta) R d\theta = \frac{\pi \ell R N_a}{2p} B_0 \cos p\varphi$$

若电机以电频率 $$\omega$$ 运行、相位角满足 $$p\varphi = \omega t + \delta$$，则端电压有效值：

$$V_a = \frac{\omega}{p} \cdot \frac{\pi}{4} \cdot 2\ell R N_a \cdot \frac{B_0}{\sqrt{2}} = \frac{\omega \pi \ell R N_a}{2\sqrt{2} p} B_0$$

可用于工作的峰值磁通密度受槽占用比例限制：

$$B_0 = B_s (1 - \lambda_s)$$

其中 $$B_s$$ 为齿部磁通密度（由磁材料饱和决定），$$\lambda_s$$ 为槽空间系数 (slot space factor)。

再求电流。电流片幅值与电流、绕组参数的关系为：

$$K_z = \frac{q N_a I}{2 \cdot 2R}, \qquad I = \frac{4R}{q N_a} K_z$$

表面电流密度又可写成体电流密度 $$J_s$$、槽空间系数 $$\lambda_s$$ 与槽深 $$h_s$$ 的乘积 $$K_z = \lambda_s J_s h_s$$，故：

$$I = \frac{4R}{q N_a} \lambda_s h_s J_s$$

把电压与电流表达式组装起来，得到额定值：

$$\lvert P + jQ \rvert = q V I = \frac{\omega}{p} 2\pi R^2 \ell \frac{B_s}{\sqrt{2}} \lambda_s (1 - \lambda_s) h_s J_s$$

这一表达式可以分解为三个因子：相互作用面积 $$A_s = 2\pi R\ell$$、表面速度 $$u_s = (\omega/p)R = \Omega R$$、以及"类牵引力"：

$$\tau^* = h_s J_s \frac{B_s}{\sqrt{2}} \lambda_s (1 - \lambda_s)$$

$$\tau^*$$ 并不严格等于牵引力，因为电流与磁通未必完全对齐，表达式因此同时包含有功与无功。槽系数乘积 $$\lambda_s(1-\lambda_s)$$ 在 $$\lambda_s = 1/2$$ 时取最大值 $$1/4$$。定子铁心中的磁通密度 $$B_s$$ 受饱和限制，而切应力密度的另一要素 $$h_s J_s$$ 则更复杂。

同步电抗与尺寸的关系也很重要。标幺同步电抗为：

$$x_d = X_d \frac{I}{V} = \frac{\mu_0 R}{p g} \frac{\lambda_s}{1 - \lambda_s} \frac{\sqrt{2} h_s J_s}{B_s}$$

反解出 $$h_s J_s$$：

$$h_s J_s = x_d g \frac{1 - \lambda_s}{\mu_0 R \lambda_s \sqrt{2}} B_s$$

给定 $$x_d$$ 时，$$h_s J_s$$（进而功率）直接与气隙 $$g$$ 成正比。要确定 $$g$$ 的上限，需要考察励磁绕组能把有效气隙磁通"抛出"多远。额定运行下励磁需要提供的标幺内电势为：

$$e_{af} = \sqrt{v^2 + (x_d i)^2 + 2 x_d i \sin \psi}$$

额定条件下 $$v = i = 1$$，故 $$e_{af} = \sqrt{1 + x_d^2 + 2x_d \sin \psi}$$。空载励磁电流由 $$B_r = \mu_0 N_f I_{f,nl}/(2 g p)$$ 给出，额定励磁为：

$$N_f I_f = \frac{2 g p (1 - \lambda_s) B_s}{\mu_0} e_{af}$$

励磁电流与转子槽结构的关系为 $$N_f I_f = \pi R \lambda_R h_R J_f$$（$$\lambda_R$$ 为转子槽空间系数，$$h_R, J_f$$ 为转子槽深与电流密度）。联立解出气隙：

$$g = \frac{\pi \mu_0 R \lambda_R h_R J_f}{2 p (1 - \lambda_s) B_s e_{af}}$$

进而得到可用的电枢表面电流密度：

$$h_s J_s = \frac{\pi x_d \lambda_R}{2\sqrt{2} e_{af} \lambda_s} h_R J_f$$

比值 $$x_d/e_{af}$$ 可以很小，对任何实用电机都不会很大，通常小于 1。实际中同步电机的标幺同步电抗很少超过约 2 到 2.25。这说明转子与定子各自都可能构成切应力密度（进而额定值）的主导限制：最优设计是两者同时达到限制的"均衡"设计。

## 五、核心 Takeaway (Takeaways)

1. 三相平衡电流产生恒幅旋转磁动势。每相磁动势是脉动波，三个脉动波的叠加中，正向旋转项相加为 $$\frac{3}{2}F\cos(p\theta - \omega t)$$，反向旋转项互相抵消。幅值恒定、以 $$\omega/p$$ 旋转是三相系统的根本特性。
2. 同步电机的稳态行为由磁链方程与电压方程完整描述。同步电感 $$L_d = L_a - L_{ab}$$，同步电抗 $$X_d = \omega L_d$$，内部电压 $$E_{af} = j\omega M I_f e^{j\theta_m}$$ 即反电动势。稳态等效电路是内电势源串联同步电抗。
3. 功率与转矩都是功角 $$\delta$$ 的正弦函数：$$P = -\frac{3}{2}(V E_{af}/X_d)\sin\delta$$，$$T = P/\omega_m$$。失步转矩在 $$\lvert\delta\rvert = 90^\circ$$ 处取极值，稳定运行仅限 $$\lvert\delta\rvert < 90^\circ$$，此条件与 $$\partial T/\partial\delta > 0$$ 等价。
4. 励磁电流控制无功功率与功率因数。过励输送无功（电流超前），欠励吸收无功并压缩稳定裕度。V 型曲线的最低点对应单位功率因数，容量图由磁场能力圆、电枢能力圆与稳定性极限围成。
5. 凸极电机中 $$X_d \neq X_q$$，功率表达式多出磁阻转矩分量 $$-\frac{3}{2}\cdot\frac{V^2}{2}\left(\frac{1}{X_q}-\frac{1}{X_d}\right)\sin 2\delta$$，该分量与励磁无关。两反应理论把电流分解到直、交轴，是后续 dq0 变换的基础。工程上暂态稳定计算常忽略凸极性。

## 六、练习与思考 (Exercises)

1. 由三相脉动磁动势的叠加，推导恒幅旋转磁动势 $$F(\theta,t) = \frac{3}{2}F\cos(p\theta - \omega t)$$。若去掉 $$c$$ 相（两相系统），合成磁动势是否仍为恒幅？说明单相系统的局限。
2. 从电流片模型出发，验证转矩表达式 $$T = (\mu_0 \pi R^3 \ell / (p g)) K_S K_R \sin p\varphi$$，并说明给定表面电流时转矩密度为何与体积无关（随线性尺寸三次方增长）。
3. 由磁链方程推导同步电感 $$L_d = L_a - L_{ab}$$，并说明平衡条件下三相电流之和为零这一条件在化简中的关键作用。
4. 一台 60 Hz、4 极（$$p = 2$$）隐极同步电机，$$v = 1.0$$、$$e_{af} = 1.2$$、$$x_d = 1.0$$，电动机运行，功角 $$\delta = -25^\circ$$。求电流、有功、无功与功率因数，并判断励磁状态。
5. 某同步电机在 $$\delta = 30^\circ$$ 下运行。若端电压不变而励磁减半，失步转矩如何变化？在相同有功负荷下，机器能否继续同步运行？用失步转矩判据说明。
6. 凸极机标幺参数 $$x_d = 1.8$$、$$x_q = 1.2$$、$$v = 1.0$$。求励磁为零（$$e_{af} = 0$$）时在 $$\delta = 45^\circ$$ 下的磁阻功率，并与同参数隐极机比较。说明磁阻转矩的来源。
