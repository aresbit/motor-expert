# 第11章: 单相感应电机 (Single-Phase Induction Motors)
> 原课程: MIT 6.685 — Electric Machines, Fall 2013 (James L. Kirtley Jr.)

## 一、本章概要 (Overview)

三相（平衡）定子电流在气隙中建立旋转磁场，感应电机由此产生转矩。单相感应电机 (single-phase induction motor) 只有一个由单相交流供电的主绕组，单相电流建立的是脉振 (pulsating) 磁场：磁场幅值随时间正弦变化，但轴线在空间固定，并不旋转。脉振磁场可分解为两个幅值减半、方向相反、同步旋转的磁场，这一处理方法称为双旋转场理论 (double-revolving field theory)。两个反向旋转的磁场在转子静止时产生大小相等、方向相反的转矩，净转矩为零，因此单相电机不能自起动。

起动需要第二个绕组，即辅助绕组（起动绕组，auxiliary/start winding），它与主绕组在空间上正交（相差 90° 电角度），并通过串联阻抗使其中电流相对主绕组电流相位超前，从而在起动时形成近似旋转的磁场。电容起动、分相（电阻起动）与罩极式是三种常见方案。本章第一部分建立单相电机的等效电路，即前向与后向磁场支路串联，并推导转矩表达式与转矩-转差特性。

课程笔记标题的后半部分"电感与电阻的建模" (Modeling of Inductances and Resistances) 讨论从几何结构解析计算绕组气隙电感、鼠笼转子折算电阻与电抗、绕组因数与斜槽因数，并处理空间谐波效应。与三相电机不同，单相电机的三倍频空间谐波不会被平衡电流消除，必须计入。

与前章关系：第 7 章建立了多相感应电机的鼠笼等效电路与解析设计评估方法，是本章的参考文档 (reference document)，本章沿用其分析风格与诸多要素；第 4 章给出绕组电感的一般表达式，本章第 3 节用同样方法计算单相双绕组的气隙电感。

## 二、物理机制与数学推导 (Physics & Math Derivation)

### 2.1 脉振磁场的分解

设主绕组为整距集中绕组，通入电流 $$i_a = I\cos\omega t$$。忽略铁心磁压降，气隙径向磁通密度的空间基波为（取轴线方向为余弦参考）：

$$B_r(\theta,t) = B_m\cos\omega t\cos\theta$$

磁场幅值随时间以 $$\omega$$ 脉振，但空间分布固定，轴线不随电流变化而移动。利用三角恒等式：

$$\cos\omega t\cos\theta = \frac{1}{2}\left[\cos(\omega t - \theta) + \cos(\omega t + \theta)\right]$$

脉振磁场被分解为两个行波。分量 $$(B_m/2)\cos(\omega t-\theta)$$ 是沿 $$+\theta$$ 方向传播的前向磁场 (forward field)，分量 $$(B_m/2)\cos(\omega t+\theta)$$ 沿 $$-\theta$$ 方向传播的后向磁场 (backward field)，两者幅值各为 $$B_m/2$$。对基波，两个分量的电气角速度均为 $$\omega$$；对极对数为 $$p$$ 的电机，前向磁场机械转速为 $$\omega/p$$，后向为 $$-\omega/p$$。

物理机制：单相电流建立的是在时间上以 $$\omega$$ 脉振、在空间上固定的磁动势波。两个幅值减半、反向旋转的行波在任意时刻叠加，恰好在固定轴线处完全对齐、在正交轴线处完全抵消，重新合成原脉振波。双旋转场理论把固定轴线的脉振磁场转化为两个独立的旋转磁场，从而把多相感应电机的既有分析方法直接应用到单相电机。

### 2.2 不能自起动的原因

转子静止（转差率 $$s=1$$）时，转子导体相对前向与后向磁场的相对速度大小相同（均为 $$\omega/p$$），方向相反。由对称性，两个磁场在转子上感应的电流模式与转矩大小相等、方向相反，净转矩为零。

前向磁场对应的转差率为 $$s$$，后向磁场对应的转差率为 $$2-s$$。每一分量各自的表现如同一个幅值减半的平衡多相磁场（第 7 章），净转矩是两者之差：

$$T = T_f(s) - T_b(2-s)$$

在 $$s=1$$ 时 $$T_f(1)=T_b(1)$$，完全抵消，净转矩为零。若转子被人为推动获得微小前向转速（$$s$$ 略小于 1），前向转矩超过后向转矩，电机产生净转矩并加速到工作点。因此单相电机能运行，但不能自起动。

转矩-转差特性在高转差区被压低：后向转矩在 $$s=1$$ 处与前向转矩完全抵消，随转子加速（$$s$$ 减小），后向转差 $$2-s$$ 增大，后向转矩逐渐减小，净转矩随之上升。与同等尺寸的平衡多相电机相比，单相电机的转矩-转差特性在近零转速区明显下凹，峰值转矩与效率均较低。

### 2.3 起动方法

单相电机通过第二个在空间上与主绕组正交的辅助绕组实现自起动。若辅助绕组电流相对主绕组电流有约 90° 的相位超前，两个正交绕组、正交电流共同建立近似圆形的旋转磁场，从而产生起动转矩。起动转矩随两电流相位差的增大而增大。三种常见方案：

- 电容起动 (capacitor-start)：辅助绕组串联电容。电容使辅助绕组支路呈容性，电流相对电压超前，从而相对主绕组电流超前约 90°。起动转矩大，可达额定转矩的数倍。电容器通常为电解型，只用于短时起动；转速达到额定值的约 75% 时，离心开关 (centrifugal switch) 切除辅助绕组，避免长期通电损耗与电容过压。

- 分相 / 电阻起动 (split-phase / resistance start)：辅助绕组用较细导线绕制，电阻与电抗之比高于主绕组，电流相位滞后电压的程度小于主绕组，两电流相位差约 30°。产生的磁场呈椭圆（弱旋转），起动转矩较小，约为电容起动的四分之一。同样用离心开关切除辅助绕组。成本低，用于起动转矩要求不高的场合。

- 罩极式 (shaded pole)：每个磁极面的一部分套有短路的铜罩极环 (shading coil)。罩极环中感应的电流延迟其所罩部分的磁通，使极面不同部分的磁通存在相位差，合成一个小的旋转磁场分量，产生很小的起动转矩。结构简单、无开关、可靠，用于小风扇等，效率较低。

### 2.4 双绕组的气隙磁场与电感

笔记 Figure 1 所示几何结构中，主绕组 A 与辅助绕组 B 相差 90° 电角度，旋转方向为逆时针（$$+\theta$$ 方向）。两绕组各阶空间谐波的径向气隙磁通密度（$$n$$ 为奇数，笔记式 1）：

$$B_r = \sum_{n=1,3,5,\ldots}\frac{4\mu_0}{n\pi}\left[\frac{N_a i_a}{2pg}k_{wna}\sin(np\theta) + \frac{N_b i_b}{2pg}k_{wnb}\sin\left(n\frac{\pi}{2}\right)\cos(np\theta)\right]$$

其中 $$N_a$$、$$N_b$$ 为主、辅绕组匝数，$$p$$ 为极对数，$$g$$ 为有效气隙，$$k_{wna}$$、$$k_{wnb}$$ 为两绕组第 $$n$$ 阶谐波的绕组因数。辅助绕组轴线在空间上超前 $$\pi/2$$，故其磁场用 $$\cos(np\theta)$$ 表示，$$\sin(n\pi/2)$$ 来自该空间位移；主绕组轴线为参考，磁场用 $$\sin(np\theta)$$。

第 $$n$$ 阶谐波磁场的磁链（$$\ell$$ 为铁心轴向有效长度，$$R$$ 为气隙半径）：

$$\lambda_{an} = \ell\int_{-\pi/p}^{0} N_a k_{wna}B_{rn}(\theta)R\,d\theta, \qquad \lambda_{bn} = \ell\int_{-\pi/(2p)}^{\pi/(2p)} N_b k_{wnb}B_{rn}(\theta)R\,d\theta$$

忽略转子电流，由磁链与电流之比得到两绕组的自感（笔记式 3）：

$$\lambda_{an} = \mu_0\frac{4N_a^2 k_{wna}^2 R\ell}{\pi n^2 p^2 g}i_a = L_{an}i_a$$

$$L_{bn} = \mu_0\frac{4N_b^2 k_{wnb}^2 R\ell}{\pi n^2 p^2 g} = \alpha_n^2 L_{an}$$

定义有效匝数比 (effective turns ratio)（笔记式 4）：

$$\alpha_n = \sin\left(n\frac{\pi}{2}\right)\frac{N_b k_{wnb}}{N_a k_{wna}}$$

$$\alpha_n$$ 的符号不影响自感，但决定各谐波磁场分量的旋转方向。对 $$n=3,7,\ldots$$，$$\sin(n\pi/2)=-1$$，$$\alpha_n$$ 为负，这些谐波（以及某个之字形分量）的旋转方向与三相电流序所指方向相反。

## 三、模型与方法精解 (Models & Methods)

### 3.1 鼠笼转子模型

单相电机的谐波分量既有正相速也有负相速。鼠笼由 $$N_R$$ 根导条 (bar) 构成，设第 $$k$$ 根导条的电流为（$$\omega_r$$ 为转子电气角频率）：

$$i_k = \operatorname{Re}\left\{I_k e^{j\omega_r t}\right\}, \qquad I_k = I_0 e^{\mp j 2\pi npk/N_R}$$

正负号对应电流波的前向或后向方向。参考文档（第 7 章）证明，这一离散导条电流组等价于面电流密度 (surface current) 的一系列空间谐波：

$$K_z = \operatorname{Re}\left\{\sum_n \frac{N_R I_0}{2\pi R}e^{j(\omega_r t \mp np\theta')}\right\}$$

$$K_z$$ 非零的谐波阶数满足 $$n = 1 + \text{integer} \times N_R/p$$。这些电流在气隙中建立的磁通密度为：

$$B_{rn} = \mp j\mu_0\frac{N_R I_0}{2\pi npg}$$

由法拉第定律，感应电场为：

$$E_n = \pm\frac{\omega_r R}{np}B_n = -j\frac{\mu_0 N_R \omega_r R}{2\pi g n^2 p^2}I_0$$

若只有最小阶项（$$n=1$$ 与 $$n=1\pm N_R/p$$）对驱动导条电流的电场贡献显著，导条回路的电压平衡为：

$$E_1 + E_{n+} + E_{n-} = Z_{\text{slot}}I_0$$

其中 $$Z_{\text{slot}}$$ 为导条槽阻抗。空间基波磁场由定子与转子电流共同产生，而高阶空间谐波电压分量只由转子电流产生。把转子电流折算到定子：若定子电流 $$I_F$$ 产生的磁场为

$$B_r = -\mu_0\frac{4N_a I_F k_{wna}}{\pi\,2pg}$$

则把转子电流折算到定子的匝数比为：

$$I_0 = \frac{4N_a k_{wna}}{N_R}I_F$$

从转子看，空间基波电场为（笔记式 9）：

$$E_1 = \left[\frac{4N_a k_{w1a}}{N_R} + j\omega_r\frac{2\mu_0 N_a k_{wna}R}{\pi g}\left(\frac{1}{(N_R+p)^2} + \frac{1}{(N_R-p)^2}\right)\right]I_F$$

把定子气隙电压与转子电场关联，需要按转子与定子之间的相对频率换算并沿绕组长度积分，得到：

$$V_{ag} = -2\ell N_a k_{w1a}\frac{\omega}{\omega_r}E_1$$

由此得到折算到定子的转子等效电路参数（笔记式 10）：

$$R_2 = \frac{8\ell N_a^2 k_{w1a}^2}{N_R}R_{\text{slot}}$$

$$X_2 = \frac{8\ell N_a^2 k_{w1a}^2}{N_R}\omega L_{\text{slot}} + \omega\frac{4\mu_0 N_a^2 k_{w1a}^2 R\ell}{\pi g}\left(\frac{1}{(N_R+p)^2} + \frac{1}{(N_R-p)^2}\right)$$

槽电阻与槽电抗可能随频率变化，需按正确的频率计算。与三相电机不同，单相电机的三倍频谐波（$$n=3,9,\ldots$$）存在且重要。高阶谐波对应的激磁电感、转子电抗与转子电阻为：

$$L_{agn} = \frac{4\mu_0 N_a^2 k_{wan}^2 R\ell}{\pi n^2 p^2 g}$$

$$X_{2,n} = \frac{8\ell N_a^2 k_{wna}^2}{N_R}\omega L_{\text{slot}} + \omega\frac{4\mu_0 N_a^2 k_{wna}^2 R\ell}{\pi g}\left(\frac{1}{(N_R+np)^2} + \frac{1}{(N_R-np)^2}\right)$$

$$R_{2,n} = \frac{8\ell N_a^2 k_{wna}^2}{N_R}R_{\text{slot}}$$

转子电阻还需按参考文档的方法修正端环 (end ring) 效应。

### 3.2 绕组因数与斜槽

单相电机的绕组通常为同心式 (concentric)，即若干同轴线圈，线圈跨距与匝数可以不同。设第 $$k$$ 个线圈匝数为 $$N_s(k)$$，跨距槽数为 $$N_c(k)$$，总匝数 $$N_a=\sum_k N_s(k)$$。线圈的电气跨距角为：

$$\phi_k = \frac{2p\pi N_c(k)}{S}$$

其中 $$S$$ 为定子槽数（假设槽距均匀，这可能是局限）。绕组因数是各线圈绕组因数的加权和：

$$k_{wna} = \sum_k \frac{N_s(k)}{N_a}\sin\left(\frac{n\phi_k}{2}\right)$$

转子常采用斜槽 (skew)，使转子与定子交链的磁通不同。自感仍如前述计算，但互感需乘斜槽因数；自感与互感之差作为漏感处理。设转子一端到另一端的斜槽角（电角度）为 $$\theta_{sk}$$，第 $$n$$ 阶谐波的斜槽因数为：

$$k_{sn} = \frac{\sin(n\theta_{sk}/2)}{n\theta_{sk}/2}$$

互感被 $$k_{sn}$$ 削弱，削弱的部分转入漏感，故激磁与漏感分量为：

$$X_{\phi n} = \omega L_{agn}k_{sn}^2, \qquad X_{1n} = \omega L_{agn}(1-k_{sn}^2)$$

斜槽削弱高次谐波耦合、改善转矩平滑性，但减少基波互感，两者需要权衡。

### 3.3 前向与后向等效电路

先只考虑空间基波。设定子两相为 a（主）、b（辅），两个等效转子相为 A、B，磁链方程为（笔记式 11）：

$$\lambda_a = L_a i_a + L_\phi i_A, \qquad \lambda_b = L_b i_b + \alpha L_\phi i_B$$

$$\lambda_A = L_\phi i_a + L_A i_A, \qquad \lambda_B = \alpha L_\phi i_b + L_A i_B$$

转子等效绕组的匝数与绕组因数与主绕组相同。转子等效相 A、B 的相互作用不便直接使用，改为前向/后向旋转分量（坐标变换）：

$$\begin{bmatrix} I_A \\ I_B\end{bmatrix} = \frac{1}{2}\begin{bmatrix} 1 & 1 \\ j & -j\end{bmatrix}\begin{bmatrix} I_F \\ I_R\end{bmatrix}, \qquad \begin{bmatrix} I_F \\ I_R\end{bmatrix} = \begin{bmatrix} 1 & -j \\ 1 & j\end{bmatrix}\begin{bmatrix} I_A \\ I_B\end{bmatrix}$$

复振幅磁链为（笔记式 13）：

$$\Lambda_a = L_a I_a + \frac{L_\phi}{2}(I_F + I_R), \qquad \Lambda_b = L_b I_b + \frac{j\alpha L_\phi}{2}(I_F - I_R)$$

$$\Lambda_F = L_\phi I_a - j\alpha L_\phi I_b + L_A I_F, \qquad \Lambda_R = L_\phi I_a + j\alpha L_\phi I_b + L_A I_R$$

定子坐标系下的电压方程。转子前向分量频率为 $$s\omega$$，后向分量为 $$(2-s)\omega$$，由 $$V_F = js\omega\Lambda_F + R_2 I_F = 0$$ 与 $$V_R = j(2-s)\omega\Lambda_R + R_2 I_R = 0$$ 得到：

$$V_a = (jX_a + R_a)I_a + \frac{jX_\phi}{2}I_F + \frac{jX_\phi}{2}I_R$$

$$V_b = (jX_b + R_b)I_b - \frac{\alpha X_\phi}{2}I_F + \frac{\alpha X_\phi}{2}I_R$$

$$0 = \frac{jX_\phi}{2}I_a + \frac{\alpha X_\phi}{2}I_b + \left(\frac{jX_A}{2} + \frac{R_2}{2s}\right)I_F$$

$$0 = \frac{jX_\phi}{2}I_a - \frac{\alpha X_\phi}{2}I_b + \left(\frac{jX_A}{2} + \frac{R_2}{2(2-s)}\right)I_R$$

这一组四个线性方程可解出四个电流 $$I_a$$、$$I_b$$、$$I_F$$、$$I_R$$。气隙功率与转子耗散功率（RMS 值）为：

$$P_{ag} = \lvert I_F \rvert^2\frac{R_2}{2s} + \lvert I_R \rvert^2\frac{R_2}{2(2-s)}$$

$$P_d = \lvert I_F \rvert^2\frac{R_2}{2} + \lvert I_R \rvert^2\frac{R_2}{2}$$

转换为机械功率：

$$P_m = (1-s)\left[\lvert I_F \rvert^2\frac{R_2}{2s} - \lvert I_R \rvert^2\frac{R_2}{2(2-s)}\right]$$

转矩：

$$T_m = \frac{p}{\omega(1-s)}P_m = \frac{p}{\omega}\left[\lvert I_F \rvert^2\frac{R_2}{2s} - \lvert I_R \rvert^2\frac{R_2}{2(2-s)}\right]$$

转矩由前向转矩减去后向转矩构成。等效电路上，主绕组输入阻抗为 $$R_a + jX_a$$ 串联前向支路与后向支路，两支路分别为激磁电抗 $$jX_\phi/2$$ 与转子支路 $$jX_A/2 + R_2/(2s)$$（后向为 $$R_2/(2(2-s))$$）的并联：

$$Z_f = \frac{jX_\phi/2 \cdot (jX_A/2 + R_2/(2s))}{jX_\phi/2 + jX_A/2 + R_2/(2s)}, \qquad Z_b = \frac{jX_\phi/2 \cdot (jX_A/2 + R_2/(2(2-s)))}{jX_\phi/2 + jX_A/2 + R_2/(2(2-s))}$$

转子静止时 $$Z_f=Z_b$$，$$I_F=I_R$$，净转矩为零。等效电路本身即体现双旋转场：后向支路对应的转矩被减去，特性在近零转速区下凹。

### 3.4 空间谐波电压方程

空间谐波只在定子侧通过电枢电流耦合在一起，在转子侧彼此独立；各阶前向/后向分量各有独立的电压平衡方程。设转子归一化转速为 $$n_s = p\omega_m/\omega = 1-s$$，第 $$n$$ 阶前向谐波与后向谐波的转差率为：

$$s_{n+} = 1 - n(1-s) = ns - (n-1), \qquad s_{n-} = 1 + n(1-s) = (n+1) - ns$$

推导：第 $$n$$ 阶前向谐波磁场极对数为 $$np$$，机械转速为 $$\omega/(np)$$；转子导体相对它的电气角速度为 $$np(\omega/(np) - \omega_m) = \omega - np\omega_m$$，归一化得 $$s_{n+}=1-n\cdot n_s$$。后向磁场机械转速为 $$-\omega/(np)$$，相对电气角速度为 $$np\omega_m + \omega$$，得 $$s_{n-}=1+n\cdot n_s$$。基波 $$n=1$$ 时 $$s_{1+}=s$$、$$s_{1-}=2-s$$，与第 3.3 节一致；转子静止时 $$n_s=0$$，两式均为 1。

考虑第 $$n$$ 阶谐波的电压方程（其余谐波结构相同）：

$$V_a = (jX_a+R_a)I_a + \frac{jX_\phi}{2}I_F + \frac{jX_\phi}{2}I_R + \frac{jX_{\phi n}}{2}I_{Fn} + \frac{jX_{\phi n}}{2}I_{Rn}$$

$$V_b = (jX_b+R_b)I_b - \frac{\alpha X_\phi}{2}I_F + \frac{\alpha X_\phi}{2}I_R - \frac{\alpha_n X_{\phi n}}{2}I_{Fn} + \frac{\alpha_n X_{\phi n}}{2}I_{Rn}$$

$$0 = \frac{jX_{\phi n}}{2}I_a + \frac{\alpha_n X_{\phi n}}{2}I_b + \left(\frac{jX_{An}}{2} + \frac{R_{2,n}}{2s_{n+}}\right)I_{Fn}$$

$$0 = \frac{jX_{\phi n}}{2}I_a - \frac{\alpha_n X_{\phi n}}{2}I_b + \left(\frac{jX_{An}}{2} + \frac{R_{2,n}}{2s_{n-}}\right)I_{Rn}$$

第 $$n$$ 阶谐波的转矩：

$$T_{mn} = \frac{np}{\omega}\left[\lvert I_{Fn}\rvert^2\frac{R_{2,n}}{2s_{n+}} - \lvert I_{Rn}\rvert^2\frac{R_{2,n}}{2s_{n-}}\right]$$

各谐波转矩直接相加。谐波数目多时耦合矩阵较大，但所得线性方程组仍易于数值求解。

单相电机的辅助电路通常串联外部阻抗 $$Z_e$$（电容，或电容与电阻并联）后接同一电压源。此时把 $$V_b$$ 方程中的 $$(jX_b+R_b)$$ 换成 $$(jX_b+R_b+Z_e)$$，两个定子方程电压均为 $$V$$：

$$V = (jX_a+R_a)I_a + \frac{jX_\phi}{2}I_F + \frac{jX_\phi}{2}I_R + \frac{jX_{\phi n}}{2}I_{Fn} + \frac{jX_{\phi n}}{2}I_{Rn}$$

$$V = (jX_b+R_b+Z_e)I_b - \frac{\alpha X_\phi}{2}I_F + \frac{\alpha X_\phi}{2}I_R - \frac{\alpha_n X_{\phi n}}{2}I_{Fn} + \frac{\alpha_n X_{\phi n}}{2}I_{Rn}$$

转子各回路方程不变。整个方程组直接可解，得到含辅助支路电流与各谐波转子电流的完整解。

## 四、推导与算例 (Derivations & Examples)

### 4.1 算例 1：气隙电感

主绕组 $$N_a=200$$ 匝、$$k_{w1a}=0.9$$，气隙半径 $$R=0.05$$ m，有效长度 $$\ell=0.08$$ m，有效气隙 $$g=0.5$$ mm，极对数 $$p=2$$。第 $$n$$ 阶自感：

$$L_{an} = \frac{4\mu_0 N_a^2 k_{wna}^2 R\ell}{\pi n^2 p^2 g}$$

基波：

$$L_{a1} = \frac{4\pi\times10^{-7}\times4\times200^2\times0.9^2\times0.05\times0.08}{\pi\times1\times4\times0.0005} = 0.104\ \text{H}$$

60 Hz 下激磁电抗 $$X_{ag1}=\omega L_{a1}=39.1\ \Omega$$。谐波按 $$1/n^2$$ 衰减：$$L_{a3}=0.0115$$ H（$$X_{ag3}=4.34\ \Omega$$），$$L_{a5}=0.00415$$ H（$$X_{ag5}=1.56\ \Omega$$）。这些气隙电感构成等效电路中激磁电抗 $$X_\phi$$ 的来源。若辅助绕组 $$N_b=240$$ 匝、$$k_{w1b}=0.9$$，基波有效匝数比 $$\alpha=(240\times0.9)/(200\times0.9)=1.2$$，辅助绕组气隙自感 $$L_{b1}=\alpha^2 L_{a1}=0.149$$ H。

### 4.2 算例 2：同心绕组绕组因数

4 极（$$p=2$$）、24 槽定子，同心绕组四个线圈：匝数/跨距分别为 20 匝/6 槽、15 匝/5 槽、10 匝/4 槽、5 匝/3 槽。总匝数 $$N_a=50$$。线圈电气跨距角 $$\phi_k = 2p\pi N_c/S = 4\pi N_c/24 = \pi N_c/6$$。基波绕组因数：

$$k_{w1a} = \frac{20}{50}\sin\frac{\pi}{2} + \frac{15}{50}\sin\frac{5\pi}{12} + \frac{10}{50}\sin\frac{\pi}{3} + \frac{5}{50}\sin\frac{\pi}{4} = 0.400+0.290+0.173+0.071 = 0.934$$

三、五、七次谐波因数：$$k_{w3a}=-0.541$$、$$k_{w5a}=0.234$$、$$k_{w7a}=-0.220$$。$$k_{w3a}$$、$$k_{w7a}$$ 为负，与 2.4 节有效匝数比符号的结论一致，对应谐波旋转方向反转。

### 4.3 算例 3：鼠笼转子折算参数

$$N_a=250$$、$$k_{w1a}=0.9$$、$$\ell=0.1$$ m、$$R=0.05$$ m、$$g=0.5$$ mm，鼠笼 $$N_R=20$$ 根导条，$$p=2$$，导条槽电阻 $$R_{\text{slot}}=100\ \mu\Omega$$，槽漏感 $$L_{\text{slot}}=0.1\ \mu\text{H}$$。由 3.1 节公式：

$$R_2 = \frac{8\times0.1\times250^2\times0.9^2\times100\times10^{-6}}{20} = 0.202\ \Omega$$

$$X_2 = X_{2,\text{slot}} + X_{2,\text{mag}}$$

槽漏项：

$$X_{2,\text{slot}} = \frac{8\times0.1\times250^2\times0.9^2\times377\times0.1\times10^{-6}}{20} = 0.076\ \Omega$$

谐波项：

$$X_{2,\text{mag}} = 377\times\frac{4\mu_0\times250^2\times0.9^2\times0.05\times0.1}{\pi\times0.0005}\left(\frac{1}{22^2}+\frac{1}{18^2}\right) = 1.57\ \Omega$$

$$X_2 = 0.076 + 1.57 = 1.65\ \Omega$$。

谐波项对应 $$n = 1\pm N_R/p = 11$$ 与 9 阶磁场，是单相/鼠笼结构特有的谐波漏抗来源，数值上超过槽漏项，不可忽略。

### 4.4 算例 4：转矩-转差特性与电容起动

取如下等效电路参数（$$V=115$$ V，60 Hz，$$p=2$$）：主绕组 $$R_a=1.0\ \Omega$$，自感电抗 $$X_a=X_{1a}+X_\phi$$，其中 $$X_{1a}=1.5\ \Omega$$、激磁电抗 $$X_\phi=50\ \Omega$$；转子折算 $$X_A = X_\phi + X_2 = 55\ \Omega$$、$$R_2=3.0\ \Omega$$。辅助绕组 $$\alpha=1.2$$、$$R_b=4.0\ \Omega$$、$$X_b=\alpha^2X_\phi+X_{1b}=74\ \Omega$$。

仅主绕组接电源时，由 3.3 节方程组数值求解，转矩-转差特性如表 1：

| 转差率 s | 净转矩 T (N·m) | 主绕组电流 (A) |
|---|---|---|
| 1.00 | 0.00 | 16.2 |
| 0.50 | 1.95 | 15.0 |
| 0.30 | 2.91 | 12.9 |
| 0.20 | 3.13 | 10.8 |
| 0.10 | 2.47 | 7.2 |
| 0.05 | 1.48 | 5.1 |
| 0.02 | 0.62 | 4.2 |

$$s=1$$ 时净转矩为零，前向与后向转矩抵消；起动后转矩上升，峰值约 3.1 N·m、出现在 $$s\approx0.2$$，随后随 $$s$$ 减小而下降，在 $$s=0$$ 处为零。$$s=1$$ 至 $$s\approx0.5$$ 区间转矩受后向磁场抑制，特性在低转速区下凹；若无起动装置，电机停在 $$s=1$$ 处。

电容起动：辅助绕组串联电容 $$Z_e = 1/(j\omega C)$$，两端同接 115 V 电源。不同电容下的起动转矩（$$s=1$$）如表 2：

| 电容 C (µF) | 起动转矩 (N·m) | 主绕组电流 (A) | 辅助绕组电流 (A) | 辅助相对主电流相位 (°) |
|---|---|---|---|---|
| 30 | 0.42 | 16.2 | 1.4 | 145 |
| 100 | 2.41 | 16.2 | 6.0 | 128 |
| 150 | 4.70 | 16.2 | 9.8 | 111 |
| 220 | 7.08 | 16.2 | 13.9 | 84 |
| 260 | 7.24 | 16.2 | 14.9 | 72 |
| 300 | 6.82 | 16.2 | 15.2 | 61 |

电容增大使辅助电流相对主电流的超前量减小，起动转矩在 $$C\approx260\ \mu\text{F}$$ 处达到峰值约 7.2 N·m，为仅主绕组时峰值转矩（3.1 N·m）的 2.3 倍。辅助电流相对主电流相位约 72°；相位接近 90°（约 $$C=200\ \mu\text{F}$$）时磁场最接近圆形，但最大起动转矩出现在相位略小于 90° 处，原因是转矩还受两电流幅值的影响。

分相（电阻起动）：辅助绕组串联电阻。本参数下最优串联电阻约 8 Ω，起动转矩约 1.7 N·m，两电流相位差约 31°，约为电容起动的四分之一，符合低成本、低起动转矩的定位。起动后切除辅助绕组，运行特性回到表 1 的仅主绕组情况。

### 4.5 算例 5：斜槽

斜槽角 $$\theta_{sk}=20°$$ 电角度时，各阶斜槽因数平方为：$$k_{s1}^2=0.990$$、$$k_{s3}^2=0.912$$、$$k_{s5}^2=0.771$$、$$k_{s7}^2=0.592$$。激磁电抗按 $$k_{sn}^2$$ 缩减，削弱的量转入漏抗 $$X_{1n}=\omega L_{agn}(1-k_{sn}^2)$$。基波激磁仅损失 1%，而七次谐波损失 41%，高次谐波被显著削弱。

## 五、核心 Takeaway (Takeaways)

1. 单相绕组通入单相电流建立脉振磁场，等价于两个幅值减半、反向旋转的磁场（双旋转场理论）。两反向磁场在转子静止时产生等大反向转矩，净转矩为零，单相电机不能自起动。
2. 起动依赖第二个正交辅助绕组：用电容或高阻绕组使其电流相位超前主绕组，形成近似旋转磁场。电容起动转矩约为电阻分相的 4 倍；起动后辅助绕组被切除。
3. 单相电机等效电路为前向与后向支路串联，转矩等于前向转矩减去后向转矩。后向转矩在高转差区显著，压低转矩-转差特性并降低效率，$$s=1$$ 处净转矩恰为零。
4. 气隙电感、鼠笼折算电阻与电抗可由几何参数解析计算：$$L_{ag}\propto N^2k_w^2R\ell/(p^2gn^2)$$，鼠笼折算参数含槽漏项与谐波项（$$n=1\pm N_R/p$$）。
5. 空间谐波（尤其三倍频谐波）在单相电机中不可忽略，谐波转差率 $$s_{n\pm}=1\pm n(1-s)$$；谐波 3、7 的旋转方向反转。斜槽因数 $$k_{sn}$$ 把部分激磁转为漏感，削弱高次谐波。

## 六、练习与思考 (Exercises)

1. 由恒等式 $$\cos\omega t\cos\theta = \frac{1}{2}\left[\cos(\omega t-\theta)+\cos(\omega t+\theta)\right]$$ 推导脉振磁场的双旋转场分解，说明两个分量的幅值与旋转方向，并解释为何转子静止时净转矩为零。
2. 单相电机转矩-转差特性在低转速区下凹。结合前向与后向转差率 $$s$$ 与 $$2-s$$，解释下凹的机制，并说明为何转子被推动后电机能加速到工作点。
3. 电容起动中，辅助电流相对主电流相位约 90° 时磁场最接近圆形，但最大起动转矩出现在相位略小于 90° 处。解释原因，并说明为何起动后要切除辅助绕组。
4. 用转差率定义推导谐波转差率 $$s_{n+}=1-n(1-s)$$、$$s_{n-}=1+n(1-s)$$，验证基波退化（$$n=1$$）为 $$s$$、$$2-s$$，并说明 $$s_{3\pm}$$ 在转子静止时的取值。
5. 由"定子电流 $$I_F$$ 与转子电流 $$I_0$$ 产生相等的基波磁动势"这一条件，验证鼠笼折算匝数比 $$I_0 = 4N_ak_{w1a}I_F/N_R$$。
6. 同心绕组设计题：$$p=2$$、$$S=24$$，线圈参数（20 匝/6 槽）、（15 匝/5 槽）、（10 匝/4 槽）、（5 匝/3 槽），求 $$k_{w1a}$$ 与 $$k_{w3a}$$，并说明 $$k_{w3a}$$ 符号的含义。
