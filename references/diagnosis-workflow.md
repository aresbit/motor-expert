# 电机故障诊断方法论 (Diagnosis Workflow)

> 与 `SKILL.md` 中的 5 步工作流配套；本节提供更细的决策树与排查动作。

## 诊断决策树

```
拿到日志+代码
├─ 日志为空/串口无输出?  → CAN/串口链路问题（见 排查A）
├─ 有 ERR 错误码?
│    ├─ ERR=D 通讯丢失 → 排查A-超时/干扰
│    ├─ ERR=A 过流 / ERR=E 过载 → 排查B-堵转过载
│    ├─ ERR=8/9 超压/欠压 → 排查C-电源
│    ├─ ERR=B/C 过温 → 排查D-热
│    └─ ERR=3/4/5 编码器异常 → 排查E-编码器
├─ 无错误码但行为异常?
│    ├─ 位置到不了/不准 → 排查F-位置精度
│    ├─ 抖动/振荡/异响 → 排查G-控制稳定性
│    ├─ 使能后立刻失能 → 排查H-使能/超时
│    └─ 高速无力 → 排查I-反电动势/弱磁
```

## 排查 A：CAN/串口通信

1. 确认串口设备存在且可打开：`ls /dev/ttyACM*`、`dmesg | grep tty`。
2. 波特率：`DM_CAN.py` 用 `serial.Serial(port, 921600)`；CAN 侧 1Mbps（RID=35 can_br）。
3. 帧解析：跑 `python scripts/parse_dm_log.py <log>`，看能否解出 `0xAA..0x55` 16 字节帧。
4. ID 核对：`addMotor(Motor)` 注册的 SlaveID（ESC_ID）必须与电机实际 ID 一致；MasterID 是反馈 ID（MST_ID）。
5. 若 `controlMIT` 打印 "Motor ID not found"：`motors_map` 里没有该 ID —— 检查 addMotor 与电机配置。
6. 偶发通讯丢失（ERR=D）：提高 RID=9 TIMEOUT；检查 CAN 终端电阻（120Ω）、屏蔽接地、线束长度。

## 排查 B：堵转/过载

1. 看反馈力矩是否持续顶到 TMAX（DM4310=10 Nm，DM-J4310-2EC=7 Nm 峰值）。
2. 折算检查：插接力需求（夹爪输出）除以齿比 g=10 再除以齿轮效率 ≈ 电机侧需力矩；若 > 电机峰值 → 机械或选型问题。
3. 若 Kp 太小 → 位置误差大 → 力矩饱和进不了线性区：增大 Kp。
4. ERR=A 过流：OC_Value 是否太低；堵转时相电流是否超 7.5A 峰值。
5. 机械检查：线束插接时夹爪是否卡在斜插位置（力没对准）→ 属感知/规划问题而非电机，报告应区分。

## 排查 C：电源

1. ERR=9 欠压：供电电压不足/线缆压降/电源限流。DM 支持 24/48V，注意电压选择影响空载转速（200 vs 400 rpm）。
2. ERR=8 超压：回馈/稳压问题，OV_Value 建议 ≤32V（24V 系统）。
3. 上电瞬间大电流：软启动。

## 排查 D：热

1. 反馈帧 D[6]=T_MOS、D[7]=T_Rotor；超 OT_Value（默认建议 100°C 电机）→ 保护失能。
2. 持续扭矩 → 铜耗 $$P_{cu}=3I^2R_s$$ 与电阻正反馈；降低占空比或提高散热。
3. 若插接循环频繁，检查 duty cycle 是否超过热额定（持续额定 3 Nm 而非峰值 7 Nm）。

## 排查 E：编码器

1. ERR=5 电机编码器校准异常：磁编偏位/退磁，需按手册重新校准电机侧编码器。
2. ERR=3 输出轴校准异常：输出侧编码器（多圈/绝对）校准丢失。
3. 位置突变/跳变：编码器信号受干扰或磁体松动。

## 排查 F：位置精度

1. 稳态误差：$$e_{ss} \approx T_{load}/K_p$$。插接力大而 Kp 小 → 增大 Kp（`controlMIT` 或 RID=27 KP_APR）。
2. 零点未设：`set_zero_position` 未调用 → 位置基准漂移。
3. 齿隙/背隙：减速器 10:1 的齿隙会放大定位误差；力位混控保持力矩可消隙。
4. 量化：MIT 位置 16 位量化步 ~0.38 mrad（±12.5 rad 范围）；若插接精度需求高于此 → 缩小 PMAX 映射范围提高分辨率。
5. 速度环/位置环增益（KP_APR/KI_APR）不合适导致跟踪误差。

## 排查 G：控制稳定性（振荡/抖动）

1. Kp/Kd 过大 → 欠阻尼振荡；先降 Kp 再调 Kd。
2. RID=11 Damp（粘滞阻尼）过低。
3. 反馈频率与控制频率不匹配（600Hz 反馈 vs 控制循环）→ 混叠。
4. 与机械谐振耦合：检查夹爪结构的固有频率。
5. 弱磁/电流环带宽（I_BW）过高导致电流环噪声。

## 排查 H：使能/超时

1. 上电后立即 enable → 失败；手册建议上电 1-2s 后再使能。
2. 旧固件：`enable_old` 需要模式偏移量。
3. 通讯超时（TIMEOUT）内未收到 CAN → 自动失能（ERR=0 或 D）。提高 TIMEOUT 或保证发送节奏。
4. `switchControlMode` 返回 False：RID=10 写入未确认；检查重试循环与固件版本。

## 排查 I：高速/反电动势

1. 电压上限：$$V \approx \omega\sqrt{(L_d i_d + \lambda_{pm})^2 + (L_q i_q)^2}$$；高速时反电动势接近母线电压 → 无力。
2. 24V→48V 提升空载转速（200→400 rpm）。
3. 弱磁：负 $$i_d$ 扩展调速范围（需驱动器支持，见 ch06）。
4. VMAX 映射范围是否低于需求转速。

## 代码修复注意

- 修改 `Limit_Param` 的 `[PMAX, VMAX, TMAX]` 时，发送与接收映射必须一致（`controlMIT` 用 `Limit_Param[MotorType]`），否则量化错乱。
- 改控制模式后必须 `save_motor_param`（0xAA）才持久化到 Flash。
- 改 Kp/Kd：先小步、观察、再调；避免一次改动过大。
- 修复后验证：重放故障场景，检查 ERR 码消失、位置/力矩曲线符合预期。
