## 一、本章概要 (Overview)

- 核心问题与动机: 电机中的力从哪里来，如何量化？本章建立理解一切电机工作的力学基础。电机种类繁多、尺寸跨度极大，从驱动手机振动的微型旋转电机，到额定功率超过吉瓦的汽轮发电机；除了旋转电机，直线电机也被广泛使用，从织机的梭子驱动到物料搬运与游乐园设施，目前正在研发用于发射飞机的大型直线感应电机。无论哪种电机，其功能最终都归结为在气隙中产生剪切应力(shear stress)。要量化这些力，需要两条并行的估算路线：热力学方法(基于能量守恒与虚功原理，面向集中参数系统)与场方法(基于麦克斯韦应力张量，面向连续介质)。两条路线在本章都从第一性原理推导。
- 与前后章节的逻辑关系: 本章是全书的基础。第1章磁路基础将用磁阻、磁动势等集中参数建立磁路模型，其本质是本章能量法的电感表达；后续同步电机、感应电机、永磁电机各章的转矩公式都源于本章"共能对转子位置角的偏导"这一结论。读者应在本章掌握"力等于场能或共能对位移的导数"这一统一视角。

## 二、物理机制与数学推导 (Physics & Math Derivation)

### 2.1 旋转电机的形态学

Figure 1 展示了一台常规感应电机的示意图。定子(stator)在外侧，其上安放绕组(winding)；多数电机的定子绕组即电枢(armature)，也就是电气功率输入端(直流电机与交直流两用电机相反，电枢在转子上，后续章节处理)。转子(rotor)安装在转轴(shaft)上，由轴承(bearing)支撑，转子表面或内部有转子导体。定子与转子之间的薄层间隙是气隙(air gap)，气隙尺寸 g 远小于机器半径 r，气隙沿轴向的长度为 ℓ。大多数(并非全部)电机采用这种形态：转子可以是圆形的，也可以是异形的——变磁阻电机(variable reluctance machine)的转子就是一块形状特殊的钢件。定子与转子通常由高磁导率材料制成，常用硅钢薄片叠压而成，槽(slot)内嵌入定子与转子导体。

Figure 2 把气隙"拉直"成机器半径趋于无穷的形式。这种画法便于分析。电机通过气隙中的剪切应力工作，同时伴随"反电压(back voltage)"等副作用。设气隙表面的平均剪切应力为 ⟨τ⟩，转子半径为 r。力作用于整个转子圆柱表面(面积 2πrℓ)，转矩为力乘以力臂 r：

$$T = 2\pi r^2 \ell\, \langle \tau \rangle$$

功率为转矩乘以转速，也等于力乘以表面线速度 u = rΩ：

$$P_m = \Omega T = 2\pi r \ell\, \langle \tau \rangle\, u$$

转矩与转子(有效)体积 V_r = πr²ℓ 之比为：

$$\frac{T}{V_r} = 2\langle \tau \rangle$$

这一关系表明：决定电机单位体积转矩能力的正是平均剪切应力 ⟨τ⟩。因此估计剪切应力是电机设计的核心问题。假设径向磁通密度与定子表面电流密度(surface current density)同为同相正弦波：

$$B_r = \sqrt{2}\,B_0\cos(p\theta - \omega t), \qquad K_z = \sqrt{2}\,K_0\cos(p\theta - \omega t)$$

其中 p 是极对数。二者同相意味着电流与磁场取向使得转矩最大化，因此给出的是"乐观"的上界。平均表面牵引(traction)为：

$$\langle \tau \rangle = \frac{1}{2\pi}\int_0^{2\pi} B_r K_z\, d\theta = B_0 K_0$$

其中利用了 ∫cos² 在一个周期内的平均值为 1/2。实际工程中，受磁性材料饱和限制的磁通密度与受冷却能力限制的电流密度共同决定了剪切应力的范围，大致从小型电机的约几 kPa 到大型强冷电机的约 100 kPa。因为功率是转矩乘以转速，高功率密度电机必然要求高转速，而转速受离心力(限制圆周速度)的约束。

### 2.2 洛伦兹力与载流导体受力

电磁力的基本来源是洛伦兹力(Lorentz force)。单个电荷 q 以速度 v 在磁通密度 B 中运动，所受的力为：

$$\vec{F} = q\,\vec{v} \times \vec{B}$$

力同时垂直于速度与磁场，方向由右手定则确定。要得到载流导体的受力，考虑导体中的电荷载流子：设载流子电荷为 q、数密度为 n、漂移速度为 v，导体截面积为 A，则电流密度与电流分别为 J = nqv、I = nqvA。体积元 dV 内的载流子数为 n dV，所受合力为：

$$d\vec{F} = (n\,dV)\,q\,\vec{v}\times\vec{B} = (\vec{J}\times\vec{B})\,dV$$

对载流子所在体积积分，并利用电流沿导体线状分布的关系 ∫J dV = ∫I d\vec{l}，得到导体元受力：

$$d\vec{F} = I\,d\vec{l}\times\vec{B}$$

$$\vec{F} = \int I\,d\vec{l}\times\vec{B}$$

物理直觉：磁场直接作用的对象是导体内运动的电荷载流子。载流子与晶格之间的动量交换把力传递给导体，宏观上表现为导体受力。力的方向是电流方向与磁场方向叉乘的结果。

### 2.3 能量守恒与虚功法

考虑一个电-机系统，它有一对电气端子(电压 v、电流 i、磁链 λ)和一个机械端子(力 f_e、位移 x)，内部以磁场储能，如图 4。假定磁场系统是保守的：储能只由状态变量决定，与"如何到达该状态"的历史无关。电气输入功率为：

$$P_e = vi = i\,\frac{d\lambda}{dt}$$

机械输出功率为：

$$P_m = f_e\,\frac{dx}{dt}$$

储能的增长率为二者之差：

$$\frac{dW_m}{dt} = P_e - P_m$$

即能量守恒的微分形式：

$$dW_m = i\,d\lambda - f_e\,dx$$

把系统从状态 b 移到状态 a 所需的能量变化：

$$W_m(a) - W_m(b) = \int_b^a \left( i\,d\lambda - f_e\,dx \right)$$

若 W_m 由状态变量 (λ, x) 描述，其全微分为：

$$dW_m = \frac{\partial W_m}{\partial \lambda}\,d\lambda + \frac{\partial W_m}{\partial x}\,dx$$

与 dW_m = i dλ - f_e dx 逐项对照，得到：

$$i = \frac{\partial W_m}{\partial \lambda}, \qquad f_e = -\frac{\partial W_m}{\partial x}$$

第二个式子即恒定磁链下虚功(virtual work)法的核心结论：

$$f_e = -\frac{\partial W_m}{\partial x}\Bigg\rvert_{\lambda=\text{const}}$$

对旋转运动，力 f_e 换成转矩 T_e，位移 x 换成角位移 θ。转矩与角位移之积和力与位移之积同为单位焦耳。对于电学线性系统，电感只依赖于机械位置：λ(x) = L(x)i。从 λ=0 开始积分(此时沿 x 的积分项为零)：

$$W_m = \int_0^\lambda \frac{\lambda'}{L(x)}\,d\lambda' = \frac{\lambda^2}{2L(x)}$$

于是：

$$f_e = -\frac{\partial W_m}{\partial x} = -\frac{\lambda^2}{2}\,\frac{d}{dx}\frac{1}{L(x)}$$

注意 d/dx(1/L) = -L'/L²，故对线性系统上式等价于(与后文共能结果一致)：

$$f_e = +\frac{1}{2}\,i^2\,\frac{dL(x)}{dx}$$

此处有一个重要警告：若把 λ = L(x)i 过早代入能量积分再求导，会得到错误结果——线性系统下产生符号错误，非线性系统下则完全错误。正确的做法是先对位置 x 求偏导，再代入电流与电感的关系。

## 三、模型与方法精解 (Models & Methods)

### 3.1 两种求力路线对比

估算电磁力有两条路线。热力学(能量)法把电机视为集中参数系统，把力写成储能对位移的导数；场方法(麦克斯韦应力张量)把力写成场量在包围物体的曲面上的积分。两种方法给出相同的力。能量法给出全局结果且便于与电路模型衔接；场方法给出力的空间分布，且不依赖理想化的无损耗假设。下表对比二者的适用范围。

| 方面 | 能量法 (虚功) | 场方法 (麦克斯韦应力张量) |
|------|---------------|-----------------------------|
| 系统描述 | 集中参数 (L, λ, i) | 连续场 (H, B, J) |
| 力的来源 | 场能/共能对位移的偏导 | 表面牵引的积分 |
| 计算对象 | 总力/总转矩 | 力密度/表面牵引的分布 |
| 适用情形 | 磁路模型、等效电路 | 气隙磁场、端部效应分析 |

### 3.2 共能

电机分析中常以电感(电流)而非磁链作为显式变量。为此定义共能(coenergy)：

$$W_m' = \sum_i \lambda_i i_i - W_m$$

对单一机械变量求微分，可证明其微分形式为：

$$dW_m' = \sum_k \lambda_k\,di_k + f_e\,dx$$

于是力是共能对位移的正偏导：

$$f_e = +\frac{\partial W_m'}{\partial x}$$

对线性系统 W_m' = ½L(x)i²，立即得到 f_e = ½i²dL/dx，与能量法结果一致。共能的优点在于：以电流为独立变量时可直接写出每个线圈的磁链，而磁链的表达通常比电感倒数更自然。这是同步电机分析中选择共能的原因。

多励磁系统(多个线圈)时，能量守恒式扩展为：

$$dW_m = \sum_k i_k\,d\lambda_k - f_e\,dx$$

总储能需对所有线圈(含互感)积分：

$$W_m = \int \vec{i}\cdot d\vec{\lambda}$$

若系统保守，W_m(λ₁, λ₂, ..., x) 单值确定，积分的具体路径不影响结果。

### 3.3 场方法的能量流：坡印廷定理

从法拉第定律与安培定律出发：

$$\nabla\times\vec{E} = -\frac{\partial \vec{B}}{\partial t}, \qquad \nabla\times\vec{H} = \vec{J}$$

用 H 点乘第一式、E 点乘第二式并相减，利用矢量恒等式 ∇·(E×H) = H·(∇×E) - E·(∇×H)：

$$\nabla\cdot\vec{S} = -\vec{E}\cdot\vec{J} - \vec{H}\cdot\frac{\partial\vec{B}}{\partial t}$$

其中 S = E×H 是坡印廷矢量(Poynting vector)，单位为瓦/平方米，描述电磁能量的流动。右端两项分别是耗散率与磁场储能变化率。用散度定理对体积积分：

$$\oint_S \vec{S}\cdot \hat{n}\,da = -\int_V \left( \vec{E}\cdot\vec{J} + \vec{H}\cdot\frac{\partial\vec{B}}{\partial t} \right) dv$$

若系统内有材料运动，采用运动学变换 E' = E + v×B，其中 v 是材料速度，E' 是在材料静止系中测得的电场：

$$\vec{E}\cdot\vec{J} = (\vec{E}' - \vec{v}\times\vec{B})\cdot\vec{J} = \vec{E}'\cdot\vec{J} + \vec{v}\cdot(\vec{J}\times\vec{B})$$

第一项是材料系中的焦耳损耗 $$\lvert J \rvert^2/\sigma$$（σ 为正时恒正定），第二项即电磁能转化为机械能的功率密度：

$$\vec{v}\cdot(\vec{J}\times\vec{B}) = \vec{v}\cdot\vec{f}$$

其中识别出力密度为洛伦兹力定律：

$$\vec{f} = \vec{J}\times\vec{B}$$

这确认了前述载流导体受力的场形式。但几何变化改变储能同样产生力，完整的电磁力描述可由纯磁场量给出，即麦克斯韦应力张量。

### 3.4 麦克斯韦应力张量

对可磁化材料，即使没有宏观电流，磁场也对材料施力。合适的力密度经验表达式为：

$$\vec{f} = \vec{J}\times\vec{B} - \frac{1}{2}(\vec{H}\cdot\vec{H})\,\nabla\mu$$

第二项体现磁化材料中磁场强度变化对力的贡献。因为 J = ∇×H、B = μH：

$$\vec{f} = \mu(\nabla\times\vec{H})\times\vec{H} - \frac{1}{2}(\vec{H}\cdot\vec{H})\,\nabla\mu$$

用矢量恒等式 (∇×H)×H = (H·∇)H - ½∇(H·H)：

$$\vec{f} = \mu(\vec{H}\cdot\nabla)\vec{H} - \frac{1}{2}\nabla(\mu\,\vec{H}\cdot\vec{H})$$

写成分量形式，第 i 个分量为：

$$f_i = \mu\sum_k H_k\,\frac{\partial H_i}{\partial x_k} - \frac{\partial}{\partial x_i}\left( \frac{1}{2}\mu\sum_k H_k^2 \right)$$

第一项改写为：

$$\mu\sum_k H_k\frac{\partial H_i}{\partial x_k} = \sum_k \frac{\partial}{\partial x_k}(\mu H_k H_i) - H_i\sum_k \frac{\partial}{\partial x_k}(\mu H_k)$$

末项是磁通密度的散度，由高斯定律恒为零：∇·B = ∇·(μH) = 0。于是力密度写成张量的散度：

$$f_i = \sum_k \frac{\partial}{\partial x_k}\left( \mu H_i H_k - \delta_{ik}\,\frac{1}{2}\mu\sum_n H_n^2 \right)$$

定义麦克斯韦应力张量(Maxwell's stress tensor)：

$$T_{ik} = \mu H_i H_k - \delta_{ik}\,\frac{1}{2}\mu\sum_n H_n^2$$

其中 δ_ik 是克罗内克 delta(δ_ik = 1 若 i = k，否则为 0)。于是 f = ∇·T。被闭合曲面 S 包围的物体所受的力，由散度定理为：

$$\vec{f} = \int_V \nabla\cdot\mathbf{T}\,dv = \oint_S \mathbf{T}\cdot\hat{n}\,da$$

表面牵引(单位面积上的力)为：

$$\tau_i = \sum_k T_{ik}\, n_k$$

重复下标时求和号可省略(爱因斯坦约定)。这一方法给出清晰图像：力通过场传递，只需在包围物体的曲面上积分表面牵引即可得总力。

### 3.5 推广到连续介质与永磁体

若系统不是有限个回路而是电流路径的连续体，共能可写成对电流的积分：

$$W_m' = \iint \lambda(\vec{a})\,d\vec{J}\cdot d\vec{a}$$

利用矢量磁位 A(满足 B = ∇×A)，单个电流丝的磁链为沿回路的线积分 λ = ∮A·d\vec{\ell}。使 dℓ 与 da 方向一致且平行于电流丝，得：

$$W_m' = \int_V \vec{A}\cdot d\vec{J}\,dv$$

对永磁体(permanent magnet)，本构关系为：

$$\vec{B} = \mu_0(\vec{H} + \vec{M})$$

其中 M 是磁化强度。磁化的效应等价于存在密度为 J* = ∇×M 的"安培电流(amperian current)"。代入共能积分，利用矢量恒等式可将积分拆为散度项与体积分，散度项在磁体外部取曲面时为零：

$$W_m' = \int_V \vec{B}\cdot d\vec{M}\,dv$$

含电流线圈与永磁体的混合系统均可由此表达统一处理。这一结果为后续永磁电机的分析提供基础。

## 四、推导与算例 (Derivations & Examples)

### 4.1 算例一：电磁铁执行器(螺线管)的拉力

Figure 5 所示的执行器由一根高磁导率的铁磁材料圆杆构成，圆杆沿轴向(x 方向)在固定的高磁导率定子内移动。线圈 N 匝，通电流 I。圆杆半径 R，与定子平端面之间的可变间隙为 x；杆的另一端与定子之间有径向间隙 g，且 g ≪ R。设径向间隙的轴向长度为 ℓ = R/2，则径向间隙面积与可变间隙面积相等，均为 πR²。

两个间隙的磁导(permeance)分别为：

$$P_1 = \frac{\mu_0 \pi R^2}{x}, \qquad P_2 = \frac{2\mu_0\pi R\ell}{g} = \frac{\mu_0\pi R^2}{g}$$

磁路上两间隙串联，总磁导为 P = P₁P₂/(P₁+P₂)，线圈电感为：

$$L = N^2\frac{P_1P_2}{P_1+P_2} = \frac{\mu_0\pi R^2 N^2}{x+g}$$

磁场储能(以恒定磁链 λ₀ 表达)为：

$$W_m = \frac{\lambda_0^2}{2L(x)} = \frac{\lambda_0^2(x+g)}{2\mu_0\pi R^2 N^2}$$

电动力为储能对 x 的负偏导：

$$f_e = -\frac{\partial W_m}{\partial x} = -\frac{\lambda_0^2}{2}\,\frac{d}{dx}\frac{1}{L(x)} = -\frac{\lambda_0^2}{2\mu_0\pi R^2 N^2}$$

系统由电流励磁，代回 λ = L(x)i = μ₀πR²Ni/(x+g)：

$$f_e = -\frac{\mu_0\pi R^2 N^2 i^2}{2(x+g)^2}$$

力为负，即趋向减小 x、闭合间隙。用共能法(恒定电流)复核：W_m' = ½Li² = ½μ₀πR²N²i²/(x+g)，f_e = +∂W_m'/∂x = -½μ₀πR²N²i²/(x+g)²，结果一致。这验证了两种方法给出的力相同，也印证了"过早代入 λ = Li"会改变符号的警告。

### 4.2 算例二：同步电机的转矩(共能法)

Figure 6 是一台简化同步电机(synchronous machine)的示意图：转子为单绕组(励磁绕组，电流 i_f)，定子为三相对称绕组(电流 i_a, i_b, i_c)均匀分布在圆周上。设磁链是转子位置的正弦函数，转子磁路"圆"对称(定子自感与相同互感不随转子位置变化)。磁链方程为：

$$\lambda_a = L_a i_a + L_{ab}i_b + L_{ab}i_c + M\cos(p\theta)\,i_f$$

$$\lambda_b = L_{ab}i_a + L_a i_b + L_{ab}i_c + M\cos\!\Big(p\theta-\frac{2\pi}{3}\Big)i_f$$

$$\lambda_c = L_{ab}i_a + L_{ab}i_b + L_a i_c + M\cos\!\Big(p\theta+\frac{2\pi}{3}\Big)i_f$$

$$\lambda_f = M\cos(p\theta)i_a + M\cos\!\Big(p\theta-\frac{2\pi}{3}\Big)i_b + M\cos\!\Big(p\theta+\frac{2\pi}{3}\Big)i_c + L_f i_f$$

用共能法求转矩。系统多励磁且含互感，共能积分必须沿多维空间中的一条合法路径进行。设转子位于角度 θ，四电流分别为 i_a0, i_b0, i_c0, i_f0，取路径为：先升高 i_a，再依次升高 i_b、i_c，最后升高 i_f：

$$W_m' = \int_0^{i_{a0}}\! L_a i_a\,di_a + \int_0^{i_{b0}}\! (L_{ab}i_{a0}+L_a i_b)\,di_b + \int_0^{i_{c0}}\! (L_{ab}i_{a0}+L_{ab}i_{b0}+L_a i_c)\,di_c + \int_0^{i_{f0}}\! \Big[M\cos(p\theta)i_{a0}+M\cos\!\Big(p\theta-\frac{2\pi}{3}\Big)i_{b0}+M\cos\!\Big(p\theta+\frac{2\pi}{3}\Big)i_{c0}+L_f i_f\Big]\,di_f$$

积分结果为：

$$W_m' = \frac{1}{2}L_a(i_{a0}^2+i_{b0}^2+i_{c0}^2) + L_{ab}(i_{a0}i_{b0}+i_{a0}i_{c0}+i_{c0}i_{b0}) + M i_{f0}\Big[i_{a0}\cos(p\theta)+i_{b0}\cos\!\Big(p\theta-\frac{2\pi}{3}\Big)+i_{c0}\cos\!\Big(p\theta+\frac{2\pi}{3}\Big)\Big] + \frac{1}{2}L_f i_{f0}^2$$

定子电感不随转子位置变化，转矩即共能对 θ 的偏导：

$$T_e = \frac{\partial W_m'}{\partial\theta} = -pM i_{f0}\Big[i_{a0}\sin(p\theta)+i_{b0}\sin\!\Big(p\theta-\frac{2\pi}{3}\Big)+i_{c0}\sin\!\Big(p\theta+\frac{2\pi}{3}\Big)\Big]$$

这就是"转矩等于共能对转子位置角的导数"在同步电机上的直接应用，也是后续同步电机章节分析的起点。

#### 电流驱动的同步电机

假定用平衡电流驱动定子，转子以同步速旋转：

$$i_{a0}=I_a\cos\omega t, \qquad i_{b0}=I_a\cos\!\Big(\omega t-\frac{2\pi}{3}\Big), \qquad i_{c0}=I_a\cos\!\Big(\omega t+\frac{2\pi}{3}\Big), \qquad i_{f0}=I_f, \qquad p\theta=\omega t+\delta_i$$

利用恒等式 cos x sin y = ½[sin(x+y) - sin(x-y)]，转矩中含 2ωt 的三项彼此间隔 120° 而相消，剩余恒定分量：

$$T_e = -\frac{3}{2}\,pM\,I_a I_f\,\sin\delta_i$$

转矩与电流转矩角 δ_i 的正弦成正比，与转子位置无关。若转子转速与各电流的频率一致，电机产生稳态转矩。实际同步电机一般不直接接电流源运行，其运行方式留待后续章节。

### 4.3 算例三：单边直线感应电机的表面牵引

Figure 7 是单边直线感应电机(linear induction machine)的简化模型：定子以高磁导率表面上的表面电流 K_z 表示，动子为高磁导率表面上的薄导电层，动子相对定子以速度 u 沿 x 方向运动。定子表面电流密度为 K_z = Re{K̄_z e^{j(ωt-kx)}}。此处忽略定子与动子有限长度等端部效应。在动子坐标系(x' = x - ut)中，相对频率为 ω_s = ω - ku，动子电流形式与定子相同。由安培定律 g·∂H_y/∂x = K_z + K_s 与法拉第定律，经代数运算得到动子表面电流与气隙磁场的复数幅值：

$$\bar{K}_s = \frac{-j\frac{\mu_0\omega_s\sigma_s}{k^2g}}{1+j\frac{\mu_0\omega_s\sigma_s}{k^2g}}\,\bar{K}_z, \qquad \bar{H}_y = \frac{j\bar{K}_z}{kg\left(1+j\frac{\mu_0\omega_s\sigma_s}{k^2g}\right)}$$

在紧贴定子的表面下方，x 方向磁场等于定子表面电流：H_x = K_z。用麦克斯韦应力张量，表面牵引 τ_x = T_xy = μ₀H_xH_y，其平均值：

$$\langle\tau_x\rangle = \frac{\mu_0}{2}\,\mathrm{Re}\{\bar{K}_z\bar{H}_y^*\} = \frac{\mu_0}{2kg}\,\frac{\frac{\mu_0\omega_s\sigma_s}{k^2g}}{1+\left(\frac{\mu_0\omega_s\sigma_s}{k^2g}\right)^2}\,\lvert\bar{K}_z\rvert^2$$

坡印廷功率流给出同一结论：动子系中 S'_y = E'_z H_x = -(ω_s/k)⟨τ_x⟩，定子系中 S_y = -(ω/k)⟨τ_x⟩。定子流入的电磁功率等于力密度乘以波速 ω/k；流入动子的功率等于力密度乘以"转差速度" ω_s/k；二者之差等于力密度乘以动子速度 u，即转换为机械形式的功率。这一关系揭示了直线感应电机的机电能量转换机制。

## 五、核心 Takeaway (Takeaways)

1. 电机的力学本质是气隙剪切应力。转矩满足 $$T = 2\pi r^2\ell\langle\tau\rangle$$，转矩密度满足 $$T/V_r = 2\langle\tau\rangle$$。平均剪切应力的量级是电机尺寸与功率密度的决定因素，工程范围约从几 kPa 到约 100 kPa。
2. 洛伦兹力 $$\vec{F} = q\vec{v}\times\vec{B}$$ 是电磁力的微观来源；载流导体受力 $$\vec{F} = \int I\,d\vec{l}\times\vec{B}$$ 与力密度 $$\vec{f} = \vec{J}\times\vec{B}$$ 是其在电路与连续介质中的宏观形式。
3. 虚功法给出统一视角：力等于磁场储能(恒定磁链下)或共能(恒定电流下)对位移的导数，即 $$f_e = -\partial W_m/\partial x = +\partial W_m'/\partial x$$。对线性系统两者都归结为 $$f_e = \tfrac{1}{2}i^2\,dL/dx$$。计算时不可过早代入 λ = Li。
4. 麦克斯韦应力张量把力表达为场量在包围曲面上的积分：$$\vec{f} = \oint \mathbf{T}\cdot\hat{n}\,da$$，表面牵引 $$\tau_i = \sum_k T_{ik}n_k$$。气隙中的切向牵引即 μ₀H_rH_θ，与表面电流密度共同给出转矩。
5. 同步电机转矩 $$T_e = -\tfrac{3}{2}pM I_a I_f\sin\delta_i$$ 是共能对转子位置角的偏导的直接结果。转矩角 δ_i 决定转矩的大小与方向，这是电机转矩控制的起点。
